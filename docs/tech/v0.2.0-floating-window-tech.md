## 2. 接口契约

### 2.1 Rust → JS(`#[tauri::command]` invoke)

| Command | 输入 | 输出 | 异常 |
|---|---|---|---|
| `timer_session_get_active` | — | `TimerSession?`(当前进行中) | DB error |
| `timer_session_get_by_id` | `{id: i64}` | `TimerSession?` | DB error |
| `timer_session_create` | `{taskTitle: string}` | `TimerSession`(新建,status='active') | taskTitle 为空 / 已有 active / DB error |
| `timer_session_update_focus_ms` | `{id: i64, focusMs: i64}` | `()`(void) | id 不存在 / 状态非 active / DB error |
| `timer_session_pause` | `{id: i64}` | `TimerSession` | id 不存在 / 状态非 active / DB error |
| `timer_session_resume` | `{id: i64}` | `TimerSession` | id 不存在 / 状态非 paused / DB error |
| `timer_session_complete` | `{id: i64}` | `TimerSession` | id 不存在 / 已 completed / DB error |
| `app_exit` | — | `()`(void) | — |
| `app_show_main_window` | — | `()`(void) | — |

### 2.2 V0.2.1 增量命令(不在 V0.2.0 范围,仅作边界参考)

| Command | 用途 | 归属 |
|---|---|---|
| `timer_session_list_recent_task_titles` | SwitchDropdown 数据源 | V0.2.1 |

### 2.3 JS → OS(Tauri 2 Window API)

| API | 用途 | 不变量 |
|---|---|---|
| `win.startDragging()` | 拖窗 | 必须在 `dragStarted=true` 之后调 |
| `win.outerPosition()` | 读物理位置 | 折叠态 resize 前必读 |
| `win.setSize()` | 折叠 / 展开 resize | 折叠 320×36,展开 360×280 |
| `win.setPosition()` | 折叠 / 展开 re-anchor | 折叠态位置保持;展开态向上展开 |
| `win.show()` / `win.hide()` | 全局快捷键切换 | 浮窗用 |

### 2.4 IPC seam

**唯一 seam**:`src/lib/tauri-bridge.ts`(`api.timerSession.*` + `api.app.*`)。

新增命令必须三处都改:
1. Rust 后端(`src-tauri/src/commands/timer_session.rs` 或 `app.rs`)
2. bridge.ts 包装(`api.*` 对象)
3. 调用点(`src/floating/` 或 `src/` 内)

任何**不**经过 bridge.ts 的 `invoke(...)` 调用都是反模式。

### 2.5 全局快捷键

**配置**:`src-tauri/src/lib.rs` 的 `Shortcut::new(Some(Modifiers::CONTROL | Modifiers::SHIFT), Code::Space)`。
**行为**:Pressed 时调 `app.get_webview_window("floating").is_visible()` → 显示 / 隐藏。
**冲突处理**:register 失败时弹系统 dialog 提示用户。

## 3. 数据模型

### 3.1 timer_session 表

| 字段 | 类型 | 约束 | 业务含义 |
|---|---|---|---|
| id | INTEGER | PK AUTOINCREMENT | 自增 |
| task_title | TEXT | NOT NULL | 任务名(UI 层限 50 字符,DB 不强约束) |
| status | TEXT | NOT NULL,CHECK IN ('active','paused','completed') | 3 态 |
| started_at | INTEGER | NULL | 开始时刻(unix timestamp ms) |
| paused_at | INTEGER | NULL | 最近一次暂停时刻(unix timestamp ms) |
| completed_at | INTEGER | NULL | 完成时刻(unix timestamp ms) |
| focus_ms | INTEGER | NOT NULL DEFAULT 0 | 累计聚焦毫秒(暂停冻结) |
| created_at | INTEGER | NOT NULL | 创建时刻(unix timestamp ms) |
| updated_at | INTEGER | NOT NULL | 最后 update 时刻(unix timestamp ms) |

### 3.2 索引

| 索引 | 类型 | 业务含义 |
|---|---|---|
| `idx_timer_session_active` | UNIQUE PARTIAL: `WHERE status='active'` | 强制全局唯一 1 个 active |
| `idx_timer_session_completed_at` | 普通:`ON (completed_at DESC) WHERE status='completed'` | V0.2.1 SwitchDropdown 数据源加速 |

### 3.3 业务不变量(由 db 强制)

1. 全局唯一 1 active(partial unique index 强制)
2. status 取值约束(CHECK 强制)
3. focus_ms 非负(DEFAULT 0)
4. paused 行 focus_ms 冻结(应用层每次 update 前 check status)
5. completed 行不可再改(status check + 应用层 guard)

### 3.4 DB 初始化

- 文件位置:`<app_data_dir>/projects.db`
- 建表 SQL:`src-tauri/src/db/schema.rs` 的 `CREATE_SQL`
- 启动时自动 `CREATE TABLE IF NOT EXISTS`

## 4. 模块边界

### 4.1 Rust 后端(`src-tauri/src/`)

| 文件 | 职责 |
|---|---|
| `lib.rs` | `run()` — Tauri Builder + 注册 dialog/log 插件 + 注册全局快捷键(Ctrl+Shift+Space)+ 注册 invoke_handler |
| `commands/mod.rs` | 8 个 timer_session commands + 2 个 app commands 的 `#[tauri::command]` 注册 |
| `commands/timer_session.rs` | timer_session 8 个 commands 的实现(get_active / get_by_id / create / update_focus_ms / pause / resume / complete / list_recent_task_titles) |
| `commands/app.rs` | app_exit + app_show_main_window 实现 |
| `db.rs` | `DbState(pub Mutex<Connection>)` + `init(app)` 初始化 DB |
| `db/schema.rs` | `CREATE_SQL` 建表 + 索引 |
| `db/timer_session.rs` | SQL CRUD + `TaskTitleRec` 类型 + partial unique index 操作 |
| `error.rs` | `AppError` 类型(从 String 包装) |

### 4.2 前端(`src/`)

| 文件 | 职责 |
|---|---|
| `lib/tauri-bridge.ts` | **唯一 IPC seam**。`TimerSession` + `TaskTitleRec` 类型 + `api.timerSession.*` + `api.app.*` 包装 |
| `main.tsx` | 主窗入口(V0.2 沿用 V0.1.6 Style Guide,**不**改) |
| `floating/main.tsx` | 浮窗入口 |
| `floating/App.tsx` | 浮窗根组件:折叠 / 展开切换 + 拖动 + 全局状态 |
| `floating/components/FoldedBar.tsx` | 折叠态 UI(320×36):任务名 + 计时器 |
| `floating/components/ExpandedPanel.tsx` | 展开态 UI(360×280):输入框 + 控制行 |
| `floating/components/InputBar.tsx` | 任务名输入(50 字符上限) |
| `floating/components/ControlRow.tsx` | 开始 / 暂停 / 恢复 / 完成按钮 |
| `floating/components/StatusDot.tsx` | 状态指示点(呼吸灯) |
| `floating/components/ContextMenu.tsx` | 右键菜单(显示主窗 / 退出) |
| `floating/hooks/useActiveTask.ts` | 订阅 active timer_session + 周期性 update focus_ms |
| `floating/hooks/useFocusTicker.ts` | 1 秒 tick 驱动 UI 计时器显示 |
| `floating/hooks/useRecentTaskTitles.ts` | V0.2.1 — SwitchDropdown 数据源(本期未启用) |

### 4.3 配置(`src-tauri/tauri.conf.json`)

**主窗**:
- label = "main",width=800,height=600
- transparent=true,decorations=true,titleBarStyle=Overlay,hiddenTitle=true

**浮窗**:
- label = "floating",width=320,height=36
- transparent=**false**(TBD,V0.2.6 P0-9 修复目标未达成),decorations=false
- alwaysOnTop=true,skipTaskbar=true,**focus=false**(不抢焦的实际实现,见 §TBD)
