## 2. 接口契约(增量)

### 2.1 新增 Rust → JS command

| Command | 输入 | 输出 | 异常 |
|---|---|---|---|
| `timer_session_list_recent_task_titles` | `{limit?: number}`(默认 5) | `TaskTitleRec[]` | DB error |

`TaskTitleRec` 类型:

```typescript
{
  task_title: string;
  last_used: number; // unix timestamp ms
}
```

### 2.2 SQL 行为

```sql
SELECT task_title, MAX(completed_at) AS last_used
FROM timer_session
WHERE status = 'completed'
GROUP BY task_title
ORDER BY last_used DESC
LIMIT ?  -- 默认 5
```

### 2.3 JS bridge

`api.timerSession.listRecentTaskTitles(limit?: number)`(`src/lib/tauri-bridge.ts`)。

### 2.4 不改 V0.2.0 命令

V0.2.0 的 8 个 commands + 2 个 app commands **契约不变**。V0.2.1 是**纯增量**。
