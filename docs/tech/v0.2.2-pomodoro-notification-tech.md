# V0.2.2 时间盒 + 完成通知 — 技术方案

> 对应 PRD: `docs/prd/v0.2.2-pomodoro-notification-prd.md`
> 对应 Domain: `docs/domain/v0.2-domain-model.md`
> 对应 ADR: `docs/domain/adr/0008`
> 范围: 时间盒(焦点 + 休息循环)+ 完成时 Windows 系统通知(toast)
> 不在范围: 主窗时间线 / 设置中心 / 自定义时间盒时长 UI / macOS 通知

---

## 1. 范围边界(bug 归属用)

### 1.1 在范围内(本方案管)

- 时间盒配置数据(焦点时长 / 休息时长 / 长休息 / 开关)**默认值**
- 时间盒运行状态机(焦点段 → 振动 / 视觉提醒 → 休息段 → ...)
- 完成时 Windows 系统 toast
- toast 降级路径(系统通知被禁时)
- 用户**开关**时间盒的入口

### 1.2 不在范围内(归其他方案/版本)

- 主窗时间线 → V0.3+
- 设置中心(完整配置 UI)→ V0.3.2
- macOS 通知 → V0.3+(V0.2 锁 Windows)
- 自定义时间盒时长 UI → V0.3.2 设置中心

### 1.3 bug 归属规则

任何 §1.1 列出的 bug → 本版本 PATCH(V0.2.2.0.<N+1>)。

- 降级路径(系统通知被禁):**TBD**

### 2.3 JS bridge

> **TBD**:`PomodoroConfig` / `PomodoroState` 类型 + `api.timerSession.*` + `api.app.showNotification` 包装在 V0.2.2 spec grill 时定。

## 3. 数据模型(增量)

### 3.1 timer_session 表

**字段**:V0.2.0 全部字段保持,**不**新增字段。
**索引**:V0.2.1 已加 `idx_timer_session_completed_at`,V0.2.2 **不**新增索引。

### 3.2 新增表(candidates)

> **TBD**:以下表结构为候选,V0.2.2 spec grill 时拍板。

| 表名(候选) | 字段(候选) | 业务含义 |
|---|---|---|
| `pomodoro_config` | `enabled INTEGER NOT NULL DEFAULT 0`,`focus_minutes INTEGER NOT NULL DEFAULT 25`,`break_minutes INTEGER NOT NULL DEFAULT 5`,`long_break_minutes INTEGER`,`cycles_before_long_break INTEGER` | 时间盒配置(全局唯一 1 行) |
| `pomodoro_state` | `id, timer_session_id, segment_type('focus'/'break'/'long_break'), started_at, ended_at, status('running'/'completed'/'cancelled')` | 时间盒运行段(每个 timer_session 多个段) |

### 3.3 业务不增量

V0.2.2 **不**改 §2.3 V0.2.0 业务不变量。3 态状态机、全局唯一 1 active 等保持。
