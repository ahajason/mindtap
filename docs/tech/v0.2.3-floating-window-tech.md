## 1. 范围边界(bug 归属用)

### 1.1 在范围内(本方案管)

- 浮窗右键菜单 = OS 层原生菜单(弹在浮窗外,不裁剪)
- 折叠态状态指示(StatusDot)位置 = 折叠态最左 inline-block flex 第 1 child(非 absolute 右上角)  <!-- [V0.2.0 误导] -->
- 浮窗边缘无黑边(`shadow: false` + `transparent: true` + `backgroundColor: #00000000`)
- 展开态内点击不误折叠回折叠态(Radix pointerdown capture 守住 panel 内点击)

### 1.2 不在范围内(归其他版本)

- 主窗时间线 / 设置中心 → V0.3+
- 复盘 / 多用户 / 同步 → V1.0
- macOS → V0.3+
- 自定义右键菜单内容 → V0.3+
- 浮窗 resize / 缩放 → 不开放 user 拖拽 resize

### 1.3 bug 归属规则

任何 §1.1 列出的 bug → 本版本 PATCH(`V0.2.0.<N+1>`)。  
本 PATCH 编号 = V0.2.0.12(本任务正式档)。

## 2. 接口契约

### 2.1 新增 Rust → JS command

| Command | 输入 | 输出 | 异常 |
|---|---|---|---|
| `show_floating_context_menu` | — | `()`(弹 OS 原生菜单,菜单点击异步回调) | 浮窗窗口不存在 → 静默失败 |

**调用链**:
```
JS onContextMenuCapture (button=2)
  → api.app.showFloatingContextMenu()  // IPC
  → show_floating_context_menu command (Rust)
  → app.autolaunch().is_enabled() (查 autostart 状态)
  → build_main_menu() (tray/menu.rs)
  → window.popup_menu(&menu) (OS 原生 popup)
  → on_menu_event 回调 (Rust) → 各 action handler
```

### 2.2 新增 on_menu_event 绑定

| 菜单 ID | 含义 | 行为 |
|---|---|---|
| `floating_toggle` | 切换浮窗显示 | toggle 浮窗 visible |
| `main_toggle` | 切换主窗显示 | 显示主窗(if hidden) / 隐藏(if visible) |
| `sep1` | — | 菜单分隔符 |
| `autostart_toggle` | 切换开机启动 | 调 `app.autolaunch().enable()` / `disable()` |
| `sep2` | — | 菜单分隔符 |
| `quit` | 退出应用 | 弹 quit 确认框(`tauri-plugin-dialog`),确认后 `app.exit(0)` |

### 2.3 JS bridge 增量

| 包装函数 | 类型 | 用途 |
|---|---|---|
| `api.app.showFloatingContextMenu()` | `() => Promise<void>` | 浮窗右键调 IPC 弹原生菜单 |

### 2.4 不改 V0.2.0 / V0.2.1 / V0.2.0.11 命令

V0.2.0 ~ V0.2.0.11 共 9 个 commands 契约不变。V0.2.3 / V0.2.0.12 是**纯增量**。

## 4. 模块边界

### 4.1 新增 Rust 模块

| 模块 | 路径 | 职责 |
|---|---|---|
| `src-tauri/src/tray/mod.rs` | 新建(改动) | `pub mod menu;` `pub mod confirm;` 模块声明 |
| `src-tauri/src/tray/menu.rs` | 新建 | `build_main_menu(autostart_enabled) → Menu` + `handle_action(app, id)` + 4~6 项菜单 |
| `src-tauri/src/tray/confirm.rs` | 新建 | `ask_quit_confirm(app) → bool`(quit 确认框,异步,不阻塞菜单事件循环) |
| `src-tauri/src/commands/floating_cmd.rs` | 新建 | `show_floating_context_menu(app, window) → Result<(), AppError>` command 实现 |

### 4.2 新增 Cargo.toml 依赖

```toml
[dependencies]
tauri-plugin-autostart = "2"  # autostart plugin(app.autolaunch())
tauri-plugin-dialog   = "2"   # quit 确认框(已存在仅升级检查)
```

### 4.3 lib.rs 改动点

```rust
// 1. 注册 autostart plugin
.plugin(tauri_plugin_autostart::init(
    tauri_plugin_autostart::MacosLauncher::LaunchAgent,
    Some(vec!["--floating-startup"]),
))

// 2. setup() 加 on_menu_event 循环绑定
.on_menu_event(|app, event| {
    match event.id().as_ref() {
        "floating_toggle" => tray::menu::handle_action(app, "floating_toggle"),
        "main_toggle"     => tray::menu::handle_action(app, "main_toggle"),
        "autostart_toggle"=> tray::menu::handle_action(app, "autostart_toggle"),
        "quit"            => tray::menu::handle_action(app, "quit"),
        _ => {}
    };
})

// 3. invoke_handler 加新 command
.invoke_handler(tauri::generate_handler![
    // ... 既有 9 commands
    commands::floating_cmd::show_floating_context_menu,
])
```
