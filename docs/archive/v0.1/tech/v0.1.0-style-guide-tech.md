## 1. 范围边界(bug 归属用)

### 1.1 在范围内(本方案管)

- 风格指南演示页 7 路由 + Sidebar
- 玻璃设计 token 落地(色彩 / 玻璃 4 要素 / 圆角 / 间距 / 字号 / 动效)

## 2. 接口契约(增量)

### 2.1 前端路由表

```
/                → redirect → /glass
/glass           → GlassPage         (玻璃 3 层渲染演示)
/tokens          → TokensPage        (4 块规范表)
/components      → ComponentsPage    (组件契约总览)
/surface         → SurfacePage       (Surface 组件演示)
/button          → ButtonPage        (Button 组件演示,三档 + 状态)
/card            → CardPage          (Card 组件演示,padding prop)
/form            → FormPage          (Label + Input 演示)
```

### 2.2 状态 / 属性层(无 IPC,纯前端)

- `<html data-window-active="true|false">` — Window 焦点状态
- `:focus-visible` — Keyboard 焦点状态(CSS 原生)
- `:hover` — Navigation 焦点状态(CSS 原生)

### 2.3 不存在 IPC 命令

V0.1 阶段无 Rust ↔ JS 通信,**没有 `invoke` 命令**,所有逻辑纯前端。

## 3. 数据模型(增量)

### 3.1 业务实体

V0.1 阶段**无业务实体**。无 SQLite 表、无 timer_session、无 app state。

### 3.2 设计 token(主题块)

主题块包含 4 块规范的具体数值:

| 维度 | 数值 | 落地位置 |
|---|---|---|
| 色彩 | 冷蓝基底 92% alpha | `src/index.css` `@theme` 块 |
| 玻璃 4 要素 | fill / blur / saturation / brightness | 同上 |
| 圆角 | button 10px / card 12px / modal 16px / pill 全圆 | 同上 |
| 间距 | 阶梯规范(G3 修复后 --spacing-5 = 20px) | 同上 |
| 字号 | 全局 text-sm = 14px | 同上 |
| 动效 | ease-out + 150-300ms | 同上 |

具体值见 `docs/design/glass-tokens.md`(已存在,跨版本)。

### 3.3 状态模型

仅 2 个前端状态:

| 状态 | 触发 | 写入 |
|---|---|---|
| Window 焦点 | focus / blur / visibilitychange | `<html data-window-active>` |
| 路由 active | React Router location match | SidebarNavLink active prop |

### 4.1 路由 + 演示页

### 4.2 设计系统落地

| 模块 | 文件 | 职责 |

| 主题块 | `src/index.css` | Tailwind 4 `@theme` + glass utilities |

| 窗口失焦钩子 | `src/hooks/useWindowActive.ts` | Window 焦点状态管理 |

### 4.3 透明窗口(仅 macOS)

| 模块 | 文件 | 职责 |
|---|---|---|
| Tauri 窗口配置 | `src-tauri/tauri.conf.json` | `transparent + titleBarStyle Overlay + hiddenTitle + macOSPrivateApi` |
| NSWindow 钩子 | `src-tauri/src/lib.rs` `setup` hook | `setMovableByWindowBackground(true)` 主线程同步调 |
| cocoa 绑定 | `src-tauri/Cargo.toml` | `cocoa + objc2` 依赖 |
| 拖动 handle | `src/components/Sidebar.tsx` + `src/components/MainHeader.tsx` | `data-tauri-drag-region` 属性 |

### 4.4 测试栈

| 工具 | 作用 | 落地 |
|---|---|---|
| vitest | 组件单测 | `*.test.ts` 与源同目录 |
| happy-dom | DOM 模拟 | vitest config |
| cargo check | Rust 静态检查 | `cd src-tauri && cargo check` |
| cargo test | Rust 测试 | `cd src-tauri && cargo test` |
| tsc --noEmit | TS 类型检查 | `npx tsc --noEmit` |
| vite build | 前端构建 | `npm run build` |

## 6. bug 归属边界(本方案生效后)

### 6.1 → 本版本 PATCH(V0.1.0.x)

任何下列路径的 bug:

- 演示页 7 路由崩溃 / Sidebar 导航失效
- 玻璃等级渲染不符合 spec(L1 22% / L2 28% / L3 36%)
- 焦点环不可见 / 鼠标点击后残留
- 整窗无法拖动 / 控件点击污染拖动
- Reduce Transparency / Reduce Motion 触发失效
- 视觉细节不一致(Button 字号圆角 / Card padding / Label gap)

### 6.2 → 另开版本

- 业务功能 bug → V0.2+
- 主窗时间线 bug → V0.3+
- 设置中心 bug → V0.3.2
