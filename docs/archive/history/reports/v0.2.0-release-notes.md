# V0.2.0 Release Notes — 浮动窗计时器（Windows 11）

> 发布日期: 2026-07-11
> Spec: [V0.2.0 浮动窗设计 spec v1.1](../specs/2026-07-11-v0.2.0-floating-window-design.md)
> Plan: [V0.2.0 浮动窗实施 plan](../plans/2026-07-11-v0.2.0-floating-window.md)

## TL;DR

V0.2.0 = 轻念 Mindtap 第一个 **Windows 业务版本**。浮动窗口 (`320×36` 折叠 + `360×280` 展开) 永远在桌面右下角，`Ctrl+Shift+Space` 唤起，输入文字 + Enter 即可开始计时；折叠态实时显示 `task_title + focus_ms` 计时器；按"完成"或失焦自动折叠；关主窗 = 隐藏主窗（不退出），浮窗右键 → 退出。

## 包含 (V0.2.0 范围内)

- ✅ **双窗口 webview**：主窗（沿用 V0.1.6 Style Guide）+ 浮动窗（V0.2 计时器）
- ✅ **本地 SQLite**：`timer_session` 单表 + partial unique index（全局唯一 1 个 active）
- ✅ **任务状态机**：3 态 `active / paused / completed`，手动完成
- ✅ **全局快捷键**：`Ctrl+Shift+Space` toggle 浮窗显隐
- ✅ **不抢焦**：Tauri 2 `WindowConfig.focus: false` + Windows 端待实测验证
- ✅ **关窗关系**：关主窗 = 隐藏（不退出）；浮窗右键 = 退出
- ✅ **历史回看 UI**：❌ V0.3 主窗时间线承担（[ADR 0006](../projects/v0.2/adr/0006-history-visibility-v0.3-main-window.md)）

### 待 Windows 端实测（T22-T24）

- [ ] 启动应用：主窗（Style Guide）+ 浮窗（折叠态）都显示
- [ ] Ctrl+Shift+Space toggle 浮窗显隐（IDE / 浏览器焦点下）
- [ ] 折叠态实时显示 task_title + focus_ms（1 秒刷新）
- [ ] 折叠态不抢焦（IDE 输入时浮窗显示不抢 IDE 焦点 — focus: false 实测）
- [ ] 点击折叠态展开（360×280 向上展开到 -100px 位置）
- [ ] 展开态输入 ≤50 字符 + Enter → active session 创建 + 折叠
- [ ] 展开态输入 + Esc / 失焦 → 折叠 + 不创建 session
- [ ] active 期间点击 → 展开显示 "暂停" + "完成"
- [ ] 点暂停 → status='paused', focus_ms 冻结
- [ ] 点恢复 → 继续累加 focus_ms（每秒写 db）
- [ ] 点完成 → status='completed'
- [ ] 关主窗 → 主窗隐藏，浮窗继续计时
- [ ] 浮窗右键 → 调 `app_exit` IPC 退出应用
- [ ] `npm run tauri build` → 出 `mindtap_0.2.0_x64-setup.exe` NSIS installer
