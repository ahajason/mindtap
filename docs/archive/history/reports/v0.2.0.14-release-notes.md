# V0.2.0.14 PATCH — 单一 root div 容器重构 + document mousedown dismiss + active session 折叠

> 发版日期: 2026-07-13
> 上一版本: V0.2.0.13 PATCH (`docs/reports/v0.2.0.13-release-notes.md`)
> commit: `a0fc00d`

## 用户视角变更 (5 行)

1. **折叠态容器减到 1 层**(不再 `floating-root-folded` + `folded-bar-inner` 嵌套)— DOM 节点更少 + 视觉只剩 1 张浮窗,WebView2 transparent 边缘更干净
2. **展开态右键在 panel 任意区域不再偶发折叠** — `panelRef` 现在覆盖整个 root div,右键即使落在 fold bar 区域也命中 panelRef.contains
3. **panel 外点击(主窗 / 系统托盘 / 其他窗口)真正关掉展开态** — document mousedown listener + `panelRef.contains()` 替代脆弱的 input blur,此前 input blur 偶发被 input event 抢先吞掉
4. **active session 自动折叠** — user L3 V0.2.0.13 重测反馈"保持展开"不顺,改成 active 时 `useEffect(()=>setExpanded(false), [session?.id])` + 控制行 active 样式高亮
5. **vitest 从子集 `23/150` 升级到全量 `146/146` PASS** — PATCH 重构后同步补 App.test.tsx 端到端 + 整合 `.fix.test.tsx` 反模式锁

## 修复的 bug (4 deviation,全部收回 V0.2.0.13 重测发现)

| Deviation | 描述 | root cause | 修复路径 | 涉及文件 |

| **B-2-1 升级版** | 展开态右键偶发折叠(panelRef 只覆盖 ExpandedPanel 子树,fold bar 右键不在 panelRef 内)| V0.2.0.13 PATCH 把 `panelRef={...}` 放在 `ExpandedPanel` 根 div;fold bar 与 status dot 右键仍在 panelRef 之外 | `panelRef` 提到 root div,覆盖整个浮窗 panel 区域,所有 panelRef.contains() 检查一次到位 | `src/floating/App.tsx` |
