#### P0-5(新增):浮窗 `set_focusable(false)` 全程生效,展开态 input 无法聚焦

**根因**:`src-tauri/src/lib.rs:39-41`(`1ba06b3 fix(floating): 不抢焦兜底` commit)
```rust
if let Some(floating) = app.get_webview_window("floating") {
    let _ = floating.set_focusable(false);
}
```

**问题**:这个 fix 意图是"折叠态不抢焦"(spec §3.7),但 Rust 启动时一次性设 `set_focusable(false)`,**展开态 input 也跟着不能 focus**。

**用户实测印证**:👤 输入框无法聚焦无法输入任何内容

**修复方案**:`src/floating/App.tsx` useEffect 里,跟 resize 一起调:
```ts
useEffect(() => {
  let cancelled = false;
  (async () => {
    try {
      if (cancelled) return;
      const win = await getCurrentWindow();
      if (expanded) {
        await win.setFocusable(true);   // 展开态允许 focus → input 能输
        await expandUpward();
      } else {
        await resizeFolded();
        await win.setFocusable(false);  // 折叠态不抢焦
      }
    } catch (err) {
      console.error("[resize/focus] failed", err);
    }
  })();
  return () => { cancelled = true; };
}, [expanded]);
```

> **决策点**:lib.rs 的 `set_focusable(false)` 是否保留?
> - 选项 A:删除 lib.rs 的兜底,完全交给 App.tsx 控制(简单但失去启动期兜底)
> - 选项 B:保留 lib.rs 兜底,App.tsx 展开时主动 `setFocusable(true)` 覆盖(推荐 — 启动期保证折叠态不抢焦,展开时手动放开)
