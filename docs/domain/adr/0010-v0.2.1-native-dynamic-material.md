# 0010 — V0.2.1 范围：平台原生动态材质

**Status**: accepted · 2026-07-28 · V0.2.1 立项

V0.2.1 的唯一业务增量是让浮窗获得经目标平台实机验证的动态环境材质，并在该能力不可用时保持基础表面可用。它不增加业务实体、不改变任务记录状态机，也不改变 V0.2.0 的四种浮窗界面状态。

## 决策

1. 先验证目标平台已有的原生材质候选；每轮只验证一个候选。
2. 原生候选未达到验收目标后，才评估一个非原生视觉候选。
3. 无论最终生产方案为何，基础表面持续保留为唯一降级路径。
4. 应用在启动时确定本次运行的材质；折叠、展开、拖动和焦点切换不重新选择。
5. 系统请求减少透明效果或减少动画时，直接使用基础表面。

## 取舍

- **先原生、后非原生候选**：优先复用目标平台能力，减少重复实现，并让平台承担环境层次表现。
- **不把视觉效果名称作为产品目标**：不同平台的材质名称并不等价，只以环境层次、边缘稳定和交互正确作为验收标准。
- **不在本期实现历史任务复用**：旧任务切换方案未进入当前产品路线；如需恢复，必须以新的版本号重新完成需求审查和验收设计。

## 后果

- V0.2.1 的业务实体、状态机和任务流程保持不变；
- V0.2.0 已验收的窗口几何、交互和持久化成为不可回归基线；
- 旧 ADR-0009 与旧任务切换资料仅保留为历史参考，不再定义 V0.2.1 范围。
