# V0.2 领域模型

> 本文档定义 V0.2 阶段的业务实体、状态机、用户流程、业务不变量。
> **不写"怎么存"(那是 L2 Tech 的事),只写"业务是什么"。**
> 跨版本适用:V0.2.0 / V0.2.1 / V0.2.2 三个 MINOR 版本共用同一份领域模型。V0.2.1 只验证浮窗动态材质，不扩展业务实体、状态机或用户流程。

## 1. 实体(Entity)

### 1.1 timer_session(任务记录)

**业务定义**:记录"我此刻在做什么 + 花了多久"的一个时间区间。是 V0.2 阶段**唯一**的业务实体,贯穿 V0.2.0 / V0.2.1 / V0.2.2 三个版本。

**关键属性**(纯业务语言):
- **任务名**:在做什么(限 50 字符)
- **状态**:这条记录当前所处阶段(3 种,见 §2 状态机)
- **累计聚焦时长**:这条记录在"进行中"状态下累计了多少毫秒(暂停时冻结)
- **开始时刻**:这条记录被创建的本地时间
- **暂停时刻**:最近一次进入"暂停"状态的本地时间(暂停时记录,其他状态可空)
- **完成时刻**:进入"已完成"的本地时间(完成后记录,其他状态可空)

**生命周期**:
- 用户输入任务名 + 按 Enter → 创建,初始状态 = "进行中",累计聚焦 = 0
- 用户暂停 / 恢复 / 完成 → 状态转换(见 §2)
- **永久保留**(不自动清理 / 不自动归档)

**业务范围决策**:timer_session 在 V0.2 阶段是**独立**实体(不与任何"task"实体绑定),见 ADR-0001。

## 2. 状态机(State Machine)

### 2.1 timer_session 状态机

```
              [进行中] ──[暂停]──► [暂停]
                  ▲  │                  │
                  │  └────[恢复]────────┘
                  │
                [完成]
                  │
                  ▼
              [已完成]
```

### 2.2 状态语义

| 状态 | 语义 | 累计聚焦时长变化 |
|---|---|---|
| **进行中** | 用户正在做这件事,计时在跑 | 每秒增加 |
| **暂停** | 用户暂时中断,计时冻结 | 不变 |
| **已完成** | 这件事做完了,记录封存 | 不变 |

### 2.3 状态转换规则

| 动作 | 前置状态 | 后置状态 | 副作用 |
|---|---|---|---|
| **开始** | (无,创建新记录) | 进行中 | 记录开始时刻 |
| **暂停** | 进行中 | 暂停 | 记录暂停时刻;累计聚焦冻结 |
| **恢复** | 暂停 | 进行中 | 累计聚焦从冻结值继续增加 |
| **完成** | 进行中 / 暂停 | 已完成 | 记录完成时刻;此行不再变化 |

### 2.4 不变量(违反即业务崩塌)

1. **全局唯一 1 个进行中**:同时刻只能有 1 条记录处于"进行中"状态
2. **暂停时累计冻结**:暂停状态的记录,累计聚焦时长**不变**
3. **完成后只读**:已完成状态的记录,任何字段都不再变化
4. **暂停/完成前提**:必须先处于"进行中"或"暂停"

---

## 3. 业务不变量(跨实体 / 跨版本)

1. **全局唯一 1 个进行中**(见 §2.4)
2. **暂停时累计冻结**(见 §2.4)
3. **完成后只读**(见 §2.4)
4. **永久保留**:timer_session 记录不自动清理 / 不自动归档
5. **单人本地**:V0.2 阶段不引入用户概念,数据只存本机
6. **任务名上限 50 字符**:超出 UI 层截断 + 提示
7. **手动完成**:完成必须由用户主动触发,系统**不**自动判定"无活动"自动完成
8. **不抢焦**:浮动窗永远不抢当前焦点(用户切到任何应用,浮窗都不打断)
9. **关主窗不退出**:关闭主窗只隐藏主窗,应用继续运行(浮窗继续计时)
10. **浮窗右键 = 退出**:浮窗右键菜单是唯一正退出入口

## 4. 用户流程(User Flow)

### 4.1 启动流程

```
用户启动应用
  → 系统同时显示主窗 + 浮动窗(都显示,见 ADR-0007)
  → 浮动窗默认在折叠态,位置在主屏右下角
```

### 4.2 创建新任务流程

```
用户单击浮动窗(折叠态)
  → 浮动窗展开 360×280
  → 用户输入任务名(限 50 字符)
  → 用户按 Enter / 点"开始"
  → 创建新 timer_session(进行中,累计=0)
  → 浮动窗折叠回 360×36,开始计时显示
```

### 4.3 暂停 / 恢复流程

```
用户单击浮动窗(折叠态,有进行中)
  → 浮动窗展开
  → 用户点"暂停"
  → 该 timer_session 状态从"进行中" → "暂停",累计聚焦冻结
  → 用户点"恢复"
  → 该 timer_session 状态从"暂停" → "进行中",累计聚焦继续
```

### 4.4 完成流程

```
用户在展开态点"完成"
  → 该 timer_session 状态从"进行中 / 暂停" → "已完成"
  → 记录完成时刻
  → 浮动窗回到空状态(等下一个任务)
  → [V0.2.2+] 系统弹出完成通知 toast
```

### 4.6 退出流程

```
用户在浮动窗上右键
  → 弹出上下文菜单
  → 用户点"退出"
  → 应用退出
```

### 4.7 关主窗流程

```
用户点主窗关闭按钮
  → 主窗隐藏,浮窗继续显示,应用继续运行
  → [TBD] 用户后续可以靠浮窗右键菜单退出 / 靠全局快捷键重新打开主窗
```
