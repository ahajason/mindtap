## 三 任务清单

### 阶段 1 — 后端 (0.5 天)

#### T22 — db::timer_session 加 `list_recent_task_titles` 函数
- **做什么**: 读路径 — `SELECT task_title, MAX(completed_at) AS last_used FROM timer_session WHERE status='completed' GROUP BY task_title ORDER BY last_used DESC LIMIT 5`
- **验收**: 返回 `Vec<TaskTitleRec> { task_title: String, last_used: i64 }`;cargo test 加 3 个用例 (空 db / 单 task / 多 task 去重)
- **commit 粒度**: 1 commit (`db(timer_session): list_recent_task_titles + 3 测试`)
- **风险**: rusqlite GROUP BY 与 INTEGER NULL 兼容性;慢路径兜底 (V0.2.1 不加索引,长期使用后性能退化由 V0.3 评估)

#### T23 — IPC `list_recent_task_titles_cmd` + invoke_handler 注册
- **做什么**: `src-tauri/src/commands/timer_session.rs` 加 `list_recent_task_titles_cmd(state) -> Result<Vec<TaskTitleRec>, AppError>`,在 `lib.rs` invoke_handler 注册
- **验收**: `cargo check` 通过;手动 invoke 命令不 panic
- **commit 粒度**: 1 commit (`feat(commands): list_recent_task_titles IPC 命令`)
- **风险**: 与现有 7 个 IPC 命令风格统一 (Result<T, AppError>)

#### T24 — tauri-bridge 加 api.timerSession.listRecentTaskTitles
- **做什么**: `src/lib/tauri-bridge.ts` 加 `listRecentTaskTitles(): Promise<TaskTitleRec[]>` + TS 类型导出
- **验收**: `npm run build` 通过;类型定义可被前端 import
- **commit 粒度**: 1 commit (`feat(bridge): timerSession.listRecentTaskTitles 类型化 wrapper`)
- **风险**: TS 类型谎言（参考 V1.3 retro）；Tauri invoke 错误处理（try/catch）

### 阶段 2 — 前端 UI + a11y (1-2 天)

#### T25 — SwitchDropdownSection 组件 + popover overlay
- **做什么**: `src/floating/components/SwitchDropdownSection.tsx` — 触发按钮 (折叠态) + popover 浮层 (展开态 9.9-C) + 列表 5 项 + loading / empty 分支
- **验收**:
  - 组件可独立 mount;5 项 task_title 渲染正确
  - 列表项点击 → 调 `onSelect(task_title)` 回调
  - popover 点击外部 → 调 `onClose()` 关闭
  - 键盘可达 (Tab / ↑↓ / Enter / Esc)
- **commit 粒度**: 1 commit (`feat(floating): SwitchDropdownSection 组件 (popover overlay)`)
- **风险**: popover 定位与点击外部检测 (useRef + click outside listener);CSS 玻璃面板 4 要素

#### T26 — SwitchDropdownSection vitest
- **做什么**: `src/floating/components/SwitchDropdownSection.test.tsx` — 3 个 it:
  1. 渲染 5 项 task_title + last_used 时间格式化
  2. 点击列表项触发 onSelect(task_title)
  3. 列表为空显示空状态 (EmptyHistoryHint)
- **验收**: `npm test` 跑通
- **commit 粒度**: 1 commit (`test(floating): SwitchDropdownSection vitest 3 项`)
- **风险**: vitest + jsdom 下 popover 定位可能需 mock useFloating (现阶段 popover 简单 absolute 定位,无 floating-ui 依赖)

#### T27 — 9.6 EmptyHistoryHint 引导气泡
- **做什么**: `src/floating/components/EmptyHistoryHint.tsx` — 渲染引导气泡:`👋 还没有历史任务,先新建一个试试?` + 点击 → focus InputBar
- **验收**: 组件独立;点击 → 触发 input ref focus
- **commit 粒度**: 1 commit (`feat(floating): EmptyHistoryHint 引导气泡 (9.6)`)
- **风险**: 跨组件 ref forwarding (React.forwardRef)

#### T28 — App.tsx 接线 + ExpandedPanel 集成 SwitchDropdownSection
- **做什么**:
  - `useRecentTaskTitles` hook (调 api.timerSession.listRecentTaskTitles + 缓存 30s)
  - `App.tsx` 展开态显示 SwitchDropdownSection (无 active 时) 或 EmptyHistoryHint (无 completed 时) 或折叠不显示 (有 active 时)
  - SwitchDropdown 选中 → InputBar 显示完整 task_title (本地 state)
  - InputBar Enter / 开始 → 创建新 session (沿用 V0.2.0 路径)
- **验收**:
  - 折叠态不变
  - 展开态无 active 时,显示 SwitchDropdownSection (有历史) 或 EmptyHistoryHint (无历史)
  - 展开态有 active 时,只显示 ControlRow (暂停/完成),SwitchDropdown 隐藏
- **commit 粒度**: 1 commit (`feat(floating): App.tsx 集成 SwitchDropdownSection + EmptyHistoryHint`)
- **风险**: 折叠展开方向与 SwitchDropdown popover 视觉一致性 (Liquid Glass spec §二玻璃 4 要素)

- **commit 粒度**: 1-2 commits (`chore(release): V0.2.1 — SwitchDropdown 上线` + `docs(report): V0.2.1 release notes`)
