# V0.2.0 浮动窗 — 实施 plan

> 本 plan 基于 [spec v1.1](../specs/2026-07-11-v0.2.0-floating-window-design.md) 锁定决策展开。
> 所有 commit 必须遵守 `dev-verify-before-commit.mdc`（system API 改动必须 dev 实测），`first-step-research.mdc`（双层调研），`archive-reference-only.mdc`（`.archive/` 不作事实）。

---

## 一 触发条件

- ✅ spec v1.1 冻结（10 项 grill 全部锁定）
- ⏳ V0.1.6 drag "fix 6" carryover closure
- ⏳ 工具链就绪（Windows 11 + Node 24 + Rust 1.96 + MSVC，已在 `install-windows-v1.0-build-log-2026-07-11.md` 验证）

---

## 二 阶段路径 (5 阶段)

```
阶段 0: 准备                (≤ 0.5 天)  — V0.1.6 carryover + AGENTS 清理
阶段 1: 基础设施            (1-2 天)    — Cargo/Vite/tauri.conf + db schema + 7 个 db 函数 + 7 个 IPC 命令 + tauri-bridge
阶段 2: 折叠态 + 快捷键 + 不抢焦 (1-2 天)  — 浮窗 webview + FoldedBar + global-shortcut + WS_EX_NOACTIVATE + 关窗关系
阶段 3: 展开态              (1-2 天)    — ExpandedPanel + InputBar + ControlRow + 折叠触发
阶段 4: 收口                (1 天)      — 测试 + 验收 + Windows build + release notes
```

总计: **5-8 天**。按 `commit-style.mdc` 业务粒度切分（小任务 = 1 commit，中 = 2，大 = 3）。

## 三 任务清单 (按 commit 粒度)

### 阶段 0 — 准备 (≤ 0.5 天)

#### T01 — V0.1.6 drag region "fix 6" carryover closure
- **做什么**: Windows 实测 V0.1.6 retro §3 提到的 drag "fix 6"（独立 drag strip 覆盖 mt-10 区），按 `dev-verify-before-commit.mdc` 走实测段
- **验收**: 用户实测 drag region 在 main / sidebar / 各 padding 区**都能拖动**；实测段写入 commit message
- **commit 粒度**: 1 commit (V0.1.6 retro 收口)
- **风险**: 如果 drag "fix 6" 在 Windows 仍不工作 → V0.2 dev 实测前暴露，需先修

#### T02 — AGENTS.md §"项目" 段清理
- **做什么**: AGENTS.md §"项目" 段当前描述 V1.0 状态（与 develop 失同步），改为 V0.1.6 / V0.2 当前事实
- **验收**: AGENTS.md 不再把 V1.0 PRD 描述为"项目当前状态"
- **commit 粒度**: 1 commit
- **风险**: 改 AGENTS.md 影响 agent 上下文，须确认改动不污染规则引用

### 阶段 1 — 基础设施 (1-2 天)

#### T03 — Cargo.toml 加 V0.2 业务依赖
- **做什么**: 加 `rusqlite` (bundled), `tokio`, `tauri-plugin-global-shortcut`, `tauri-plugin-dialog`
- **验收**: `cargo check` 通过；Windows 工具链下编译成功
- **commit 粒度**: 1 commit
- **风险**: 国内 crates.io 镜像问题（参考 D45 rsproxy 配置）

#### T04 — tauri.conf.json 加 floating window 配置
- **做什么**: `app.windows[]` 加 floating window — 320×36 transparent + 跳过 dock + always-on-top + decorations=false
- **验收**: `tauri dev` 启动看到 2 个窗口（main + floating）
- **commit 粒度**: 1 commit
- **风险**: WebView2 transparent 在 Windows 11 实测前行为不确定（参见 spec R2）

#### T05 — vite.config.ts 加 floating 入口
- **做什么**: vite 多入口配置（main + floating）+ `floating.html` 新建
- **验收**: `npm run build` 产出 `dist/index.html` + `dist/floating.html`
- **commit 粒度**: 1 commit
- **风险**: vite 多入口 alias 配置

#### T06 — src-tauri/src/db/schema.rs 实现
- **做什么**: 按 spec §四 SQL 创建 `timer_session` 表 + 2 索引（active 唯一 + completed_at 倒序）
- **验收**: 应用首次启动自动创建 db 文件 + schema
- **commit 粒度**: 1 commit
- **风险**: rusqlite 类型映射（INTEGER NULL 可空字段处理）

#### T07 — src-tauri/src/db/timer_session.rs 6 个 db 函数
- **做什么**: `init` / `create` / `get_active` / `update_focus_ms` / `pause` / `resume` / `complete` (7 个函数)
- **验收**: 单元测试覆盖；partial unique index 验证全局唯一 1 个 active
- **commit 粒度**: 2 commits（函数定义 + 单元测试）
- **风险**: db 函数并发安全（Mutex<Connection> 已锁住，但要注意锁内不 await）

#### T08 — src-tauri/src/commands/timer_session.rs 7 个 IPC 命令
- **做什么**: `timer_session_init` / `timer_session_create` / `timer_session_get_active` / `timer_session_update_focus_ms` / `timer_session_pause` / `timer_session_resume` / `timer_session_complete`
- **验收**: invoke_handler 注册 + 单元测试覆盖
- **commit 粒度**: 2 commits（命令定义 + 测试）
- **风险**: invoke_handler 串行注册顺序

#### T09 — src-tauri/src/lib.rs 注册 IPC + DbState
- **做什么**: `tauri::Builder` 加 `.manage(DbState)` + `.invoke_handler(...)` 注册 7 个命令
- **验收**: Tauri dev 启动后 `window.__TAURI__.invoke` 可调用所有命令
- **commit 粒度**: 1 commit

#### T10 — src/lib/tauri-bridge.ts 类型化 7 个 invoke
- **做什么**: TypeScript 类型化 7 个 API + 输入/输出类型
- **验收**: 前端调用全部 type-safe
- **commit 粒度**: 1 commit

### 阶段 2 — 折叠态 + 快捷键 + 不抢焦 (1-2 天)

#### T11 — src/floating/main.tsx + floating.html 入口
- **做什么**: 浮窗 webview 入口（参照 V0.1.6 main.tsx 结构，但加载 App_floating）
- **验收**: 浮窗 webview 启动后只显示浮窗组件
- **commit 粒度**: 1 commit

#### T12 — src/floating/App.tsx + 折叠态组件
- **做什么**: 折叠态 UI + FoldedBar + GlassSurface（沿用 V0.1.6 Style Guide 的 GlassSurface）
- **验收**: 浮窗折叠态显示 task_title + focus_ms 计时器
- **commit 粒度**: 2 commits（基础组件 + 折叠态集成）

#### T13 — useActiveTask + useTick hooks
- **做什么**: `useActiveTask` 从 db 读当前 active session；`useTick` 1 秒 timer 触发 re-render
- **验收**: 折叠态计时器每秒刷新；active session 切换时自动更新
- **commit 粒度**: 1 commit
- **风险**: useTick 不能跨窗口同步（浮窗关闭再开时是否重置？）

#### T14 — tauri-plugin-global-shortcut 注册 Ctrl+Shift+Space
- **做什么**: 启动时注册 Ctrl+Shift+Space → toggle 浮窗显示/隐藏
- **验收**: IDE 焦点下按 Ctrl+Shift+Space 浮窗 toggle；冲突探测 + 弹 message
- **commit 粒度**: 1 commit
- **风险**: Windows 上 Ctrl+Shift+Space 可能被输入法 / 系统占用（spec R3）

#### T15 — WS_EX_NOACTIVATE 实现
- **做什么**: 通过 `RawWindowHandle` 拿浮窗 HWND → `SetWindowLongPtr(hwnd, GWL_EXSTYLE, ...)` 加 `WS_EX_NOACTIVATE`
- **验收**: dev 实测 — IDE 焦点下浮窗显示不抢焦点（参见 spec §六 验收标准）
- **commit 粒度**: 1 commit
- **风险**: Tauri 2 RawWindowHandle API 限制；如失败回退到 spec R7 候选 B/C

#### T16 — 关窗关系处理（关主窗=隐藏；浮窗右键=退出）
- **做什么**: 主窗 close handler → `window.hide()` 而非 exit；浮窗加右键菜单（含"退出"项）
- **验收**: spec §六 验收 — 关主窗主窗隐藏、浮窗继续计时；浮窗右键"退出"应用退出
- **commit 粒度**: 1 commit
- **风险**: tauri::Window::on_window_event 拦截 close 行为

### 阶段 3 — 展开态 (1-2 天)

#### T17 — ExpandedPanel 组件
- **做什么**: 展开态 360×280 容器，包含 InputBar + ControlRow + StatusDot
- **验收**: 折叠态点击展开；失焦/Enter/Esc 折叠
- **commit 粒度**: 2 commits（容器组件 + 折叠触发逻辑）

#### T18 — InputBar (50 字符 task_title 输入)
- **做什么**: textarea/input + placeholder + 字符计数（0/50）
- **验收**: 输入超过 50 字符截断；Enter = 开始；Esc = 取消
- **commit 粒度**: 1 commit

#### T19 — ControlRow (开始/暂停/恢复/完成 按钮)
- **做什么**: 4 按钮按 status 动态显示；点击触发对应 IPC 命令
- **验收**: spec §六 验收 — 暂停/恢复/完成 流程
- **commit 粒度**: 2 commits（UI 集成 + IPC 绑定）

#### T20 — StatusDot (折叠态状态指示)
- **做什么**: 折叠态右上角小圆点 — active=绿 / paused=橙 / completed=灰
- **验收**: 状态切换时圆点颜色实时更新
- **commit 粒度**: 1 commit

#### T21 — 折叠触发逻辑统一收口
- **做什么**: 把"Enter/Esc/失焦/点开始/完成/Ctrl+Shift+Space"6 个折叠触发汇总到一个 handler
- **验收**: 6 个触发路径全工作；重复触发不崩溃
- **commit 粒度**: 1 commit

## 五 dev 实测 checklist (按 dev-verify-before-commit.mdc)

每个 commit 前必须实测（Windows 11 24H2）:

- [ ] 折叠态启动不抢焦（IDE 输入测试）
- [ ] 折叠态计时器每秒刷新
- [ ] Ctrl+Shift+Space toggle（IDE / 浏览器 / 任意 app 焦点下）
- [ ] 展开态输入 + Enter → active + 折叠
- [ ] 展开态输入 + Esc → 折叠 + 不创建 session
- [ ] 展开态失焦 → 自动折叠
- [ ] 暂停 → focus_ms 冻结；恢复 → 继续累加
- [ ] 完成 → status='completed'，折叠态显示完成态
- [ ] 关主窗 → 主窗隐藏，浮窗继续计时
- [ ] 浮窗右键菜单 → 退出应用
- [ ] 重启应用 → db 持久化恢复（active / paused / completed 状态正确）
- [ ] a11y：折叠态对比度 ≥ 4.5:1 + `aria-label` 正确（用 NVDA 或 Narrator 测）
