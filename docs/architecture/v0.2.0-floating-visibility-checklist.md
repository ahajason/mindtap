# V0.2.0 浮窗可见性 7 层 Checklist

> **按 `archive-reference-only.mdc` 严格分类**：本文件是**事件清单（历史失败模式事实）**，**不是**设计意图或"修复方案值得复用"的依据。`.archive/` 整体非事实，引用须标注来源 + 不预设沿用。
>
> 来源：`.archive/docs/architecture/floating-visibility-checklist.md`（V1.0 时代浮动窗口快速记录项目的浮窗 7 层自上而下验证清单）。

任何 V0.2.0 浮窗改动后必须**自上而下逐层 PASS**，才能算"完成"。漏掉任何一层 → 用户看不到浮窗 → 返工。

## 7 层 + 验证手段

| # | 层 | V0.2.0 验证手段 | 失败症状 |
|---|---|---|---|
| 1 | **Tauri 进程存活** | Task Manager `mindtap.exe` PID + WorkingSet | 进程崩溃 / 退出 |
| 2 | **webview 已创建** | tauri.conf.json `windows[1].label=floating` 注册 + DevTools Console 无 "window load failed" | `ensure_window` 失败 |
| 3 | **webview 状态 visible** | `npm run tauri dev` 启动后浮窗显示在右下角 | 浮窗被 `hide()` 后没回 show |
| 4 | **webview 内容加载** | DevTools Console 无 error；React mount 成功（`useActiveTask` 无 unhandled rejection） | floating.html 加载失败 / React crash |
| 5 | **物理尺寸正确** | DevTools Network/Elements 检查浮窗 DOM 是 320x36（折叠）/ 360x280（展开）；setSize 后 outerSize 同步 | webview 卡 320×36，展开态被裁 |
| 6 | **物理位置避开系统 chrome** | Windows 11 任务栏高 ~48px；浮窗位置 y ≥ 主屏高度 - 36 - 100（spec §3.1 grill 9.5 B） | 浮窗被任务栏遮住 |
| 7 | **视觉样式挂载** | DevTools Elements 检查浮窗顶层 div `className` 含 `glass-l2` / `glass-l3` token；Liquid Glass CSS 加载 | 玻璃外观失效（透明不可见）|

## 已知盲区（commit 前必查）

| 盲区 | 原因 | V0.2.0 防御 |
|---|---|---|
| **Playwright e2e 用 Tauri mock 完全绕过 capability/物理层** | `window.__TAURI_INTERNALS__.invoke = mock` 不触发 Tauri runtime | 任何浮窗改动必须跑 Windows 端 `npm run tauri dev` 实测，不只 vitest + cargo test |
| **CSS 契约测试 ≠ 挂载测试** | jsdom 不渲染 layout，scrollHeight=0 | vitest 用 happy-dom + `expect(root.className).toMatch(/floating-root/)` |
| **Windows 11 任务栏遮默认位置** | tauri.conf.json 没指定 x/y | 浮窗位置由 spec §3.1 grill 9.5 锁定为右下-100px（避任务栏 48px） |
| **rust command + frontend wrapper 已实现 ≠ 已 wire** | Tauri 2 IPC 注册 + tauri-bridge.ts 包装 ≠ 前端调用 | `grep "api\.\|invoke("` 后必须有调用点 — **V0.2.0 浮窗右键 → 退出 app_exit 是真实漏洞**，TBD 修 |
| **jsdom 不渲染 layout, scrollHeight=0** | vitest 默认 jsdom | 浮窗 resize 测试用 happy-dom 或 Playwright |

## 修改浮窗的完成定义 (DoD)

```bash
# 1. 静态检查 — cargo test 100% green
cargo test --manifest-path src-tauri/Cargo.toml --lib

# 2. 前端编译检查 — tsc / vite build 干净
npx tsc --noEmit
npm run build

# 3. Lint — clippy / fmt / eslint
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets
cargo fmt --manifest-path src-tauri/Cargo.toml --check

# 4. 运行时检查 — Windows 端 tauri dev 跑 7 层 PASS（必须，不接受 mock）
npm run tauri dev
# + spec §六 17 条验收实测

# 5. Release — tauri build 出 NSIS installer
npm run tauri build
```

**任何一项 FAIL → 不得 commit**，继续修。

## V0.2.0 与 V1.0 的差异（不预设复用 .archive 修复方案）

| 维度 | V1.0 (.archive/) | V0.2.0 |
|---|---|---|
| 平台 | macOS NSPanel + WebView2 | Windows WebView2 only |
| 不抢焦 | NSPanel `setFloatingPanel` + `becomeKeyOnly` | Tauri 2 `WindowConfig.focus: false` + (待实测) |
| 全局快捷键 | ⌘+Shift+Space (macOS) | Ctrl+Shift+Space (Windows) |
| webview 嵌入 | NSHostingView (SwiftUI 混合) | 纯 WebView2 (无 Swift) |
| Liquid Glass | NSVisualEffectView (95% 还原) | CSS `backdrop-filter` + Tailwind tokens (80% 还原) |
| 浮窗位置 | macOS 顶栏 ~25px 避让 | Windows 11 任务栏 ~48px 避让 |
| 关窗关系 | 仅 NSPanel 浮窗关闭 | 关主窗=隐藏 + 浮窗右键=退出 |
