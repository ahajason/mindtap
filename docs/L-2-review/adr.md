# ADR 0014: V0.2.2 范围 = 阶段二（可信台账与复盘），时间盒方案废弃

- **状态**: ✅ 已采纳
- **日期**: 2026-08-02
- **决策者**: 用户 + Claude Code

## 背景

- V0.2.0 立项时，ADR-0008 把 V0.2.2 定义为「时间盒（番茄）+ 完成通知」，配套旧 pomodoro PRD/tech（已 superseded 并废弃）。
- V0.2.1 三态重构后，产品方向演进为「个人工作台账」（PRD 主文档），阶段一（工作台账核心）已落地并实机验证通过。
- PRD 主文档 L46 明确「不做番茄钟 / 倒计时 / 专注训练（计时只为'看见投入'）」——**番茄工作法（时间盒）与 Mindtap 基因冲突**。
- 阶段二定义为「可信台账与复盘」（PRD 阶段二 2.1 每日复盘 / 2.2 活动信号与智能提示 / 2.3 主窗管理）。

## 决策

1. **V0.2.2 = 阶段二**（可信台账与复盘），不再是「时间盒 + 完成通知」。
2. **时间盒（番茄工作法）整体废弃**——与产品基因冲突，不并入、不排期。
3. **完成通知的决策点保留**，并入阶段二 2.2（打扰级别配置）——PRD 4.2 信号分级表「计时在跑 + 人离开（空闲超时）」＝ 系统通知（可关），「已完成任务」toast 时机从「完成」改为「归档时」。
4. **前置修复**：阶段一 1.4 的「系统通知 XX 已自动暂停」未真正生效（前端抢跑 + 权限未请求 + 无可关开关），作为阶段二 2.2 的前置项补齐（阶段二 task 建立时纳入）。

## 范围

| 任务 | 范围 |
|---|---|
| 2.1 每日复盘视图 | 主窗一屏四块（今日完成清单含时长 / 时间分布 / 晾着任务 / 未覆盖时段），未闭合任务逐条顺延/完成/删除 |
| 2.2 活动信号与智能提示 | 前台应用监听，10 分钟未计时 → 浮窗视觉强化 + 建议；一键确认建卡/忽略；打扰级别可配、可全局关；含 1.4 系统通知补齐 |
| 2.3 主窗管理 | 全列表（搜索 / 按状态筛选 / 编辑）、删除 5 秒撤销 |

## 反向后果

- 如果将来用户需要「专注节奏」（番茄钟），需作为**新增方向**重新立项（阶段三候选），不复用时间盒旧方案。
- 完成通知若在归档时弹太多会扰民——需 grill「哪些归档值得通知」，作为 2.2 打扰级别配置的一部分收敛。

> 本需求为「可信台账与复盘」（阶段二）。产品场景见主文档阶段二；领域基础复用工作台账三态模型与激活日志。
