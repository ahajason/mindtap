# fix(main-window): 启动首帧透明闪烁

> 状态：pending（延后）
> 版本：待主窗口启动体验路线确定
> 优先级：P2
> 阻塞关系：不阻塞 V0.3.0 浮窗动态材质

## Why

Windows 100% DPI 基线复验中，主窗口正常出现，但启动首帧会短暂透明闪烁。该症状发生在主窗口，不属于只作用于浮窗的 V0.3.0 动态材质范围。

## What

- 使用 Windows 启动录屏建立可重复的首帧反馈回路；
- 区分原生窗口初始背景、页面首帧背景和应用样式挂载时序；
- 只有证据证明与浮窗共用同一错误配置时，才允许合并归因；否则作为独立主窗口问题修复。

## Done when

- [ ] Windows 启动录屏稳定捕获透明闪烁；
- [ ] 找到最先偏离预期的原生窗口或页面层；
- [ ] 建立能在旧实现判红的契约或最小人工回路；
- [ ] 修复后主窗口首帧不再透明闪烁；
- [ ] 浮窗启动、不抢焦和透明边缘不回归；
- [ ] Windows 实机复验通过并记录环境。

## 明确不做

- 不借 V0.3.0 浮窗材质修改主窗口；
- 不用延时隐藏窗口掩盖未定位的首帧根因；
- 不以静态构建通过代替 Windows 启动录屏。
