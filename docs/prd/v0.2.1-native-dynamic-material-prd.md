## 一、背景与目标

### 1.1 项目背景

当前浮窗已具备可用的半透明表面，但现有基础表面不能证明它会采样 Windows 桌面或后方窗口的环境层次。Windows 实机反馈仍可能看到扁平、泛灰的表面；这不是 V0.2.0 四状态、物理窗口几何或交互链路未完成的证据，必须作为独立版本验证。

### 1.2 产品目标

让 Windows 11 用户在浮窗中可感知后方环境的半透明层次，同时保持 V0.2.0 已验收的可读性、边缘完整性、窗口位置和全部交互。

本期成功的优先级依次为：

1. 原有交互正确且窗口边缘稳定；
2. 折叠、展开和显示缩放下稳定；
3. 性能可接受；
4. 后方环境层次可被感知。

不以单纯增加透明度或视觉强度判定成功。

### 1.3 核心用户

使用 Windows 11 的单人本地用户，在工作桌面上长期保留浮窗，同时在不同应用和背景间切换。

## 二、需求范围

### 2.1 本期做

- 为浮窗验证并选择一条平台动态材质方案；
- 当已选方案不可用时，保留稳定、可读的轻量表面；
- 在 Windows 11 上用完整场景矩阵验证实际选定方案；
- 在系统要求减少透明效果或减少动画时，直接使用轻量表面。

### 2.2 本期不做

- 不修改主窗口、其他弹窗或全局视觉风格；
- 不修改浮窗的四状态、尺寸、拖动、右键菜单、不抢焦或计时持久化行为；
- 不提供用户可见的材质开关、持久化选择或运行中手动切换；
- 不将 Apple 平台名称或任一具体技术名作为验收结果；
- 不在未完成比较与实机验证前引入新的非原生视觉方案。

---

## 三、用户可观察需求

### 3.1 环境层次

用户在浅色、深色和高对比或纹理背景前使用浮窗时，能从浮窗表面感知后方环境的层次变化；文字和控制内容仍清晰可读。

如果系统或设备不支持所选能力，用户仍能看到完整可读的浮窗，不会看到空白、漏底、黑边、灰边或不连续圆角。

### 3.2 稳定的单次运行

应用启动后，每次运行只使用一个已选定的材质方案或轻量表面。用户折叠、展开、拖动浮窗、切换焦点或改变任务状态时，材质不重新探测、不闪回为另一种材质，也不在方案间来回切换。

如果非原生视觉方案在初始化或显示时失败，本次运行可一次性降级为轻量表面，并保持到退出。

### 3.3 既有浮窗行为不回归

无论选择何种材质，用户仍可：

- 在空闲和活动的折叠、展开四种状态间正常操作；
- 在折叠和展开状态拖动窗口，且窗口位置和宽度稳定；
- 使用系统原生右键菜单；
- 在启动、显示及状态切换时不被非主动操作抢走输入焦点；
- 重启后继续看到原有的任务和计时状态。

### 3.4 可观察的失败条件

出现以下任一结果即表示候选不通过，必须恢复轻量表面后再验证下一候选：

- 黑边、灰边、漏底、顶部白线、圆角不连续；
- 折叠、展开、拖动、焦点切换或显示缩放时闪烁、跳位或内容裁剪；
- 可见卡顿、输入无响应，或破坏既有四状态与窗口交互；
- 浮窗仍仅呈现扁平泛灰表面，无法感知后方环境层次。

## 四、候选与选择规则

候选按以下顺序逐个验证：

1. Windows 平台的第一原生候选；
2. 未通过时验证第二原生候选；
3. 仅当两种原生候选均未通过，或一个非原生视觉候选在同一实机矩阵中有明确更优证据时，才评估该候选。

每次只验证一个候选并完成一轮 Windows 实机矩阵；不允许同时接入多个候选后凭主观印象选择。

非原生视觉候选进入评估前，必须确认其适用于当前应用、授权条件可接受、能够在透明浮窗中工作，并能在失败时降级为轻量表面。未通过任一条件不得进入生产。

## 五、非功能需求

| 类型 | 要求 |
|---|---|
| 支持基线 | Windows 11 是完整动态材质的支持与验收平台 |
| 降级 | Windows 10、缺少相应系统能力、减少透明或减少动画时保持基础可用性 |
| 稳定性 | 不得损害既有四状态、拖动、原生菜单、不抢焦和计时持久化 |
| 性能 | 首版以 Windows 实机主观体验为 hard gate；仅在出现争议时补充可复现采样 |
| 验收 | 静态检查或自动化测试不能代替 Windows 11 实机结论 |

---

## 六、Windows 实机验收

在 Windows 11 上，分别对浅色、深色和高对比或纹理背景检查：

- 空闲折叠、空闲展开、活动折叠、活动展开；
- 聚焦与非聚焦；
- 100%、125%、150% 显示缩放；
- 折叠、展开、拖动、窗口大小变化和右键菜单。

通过条件是：内容可读、边缘连续、位置和内容稳定、交互顺畅，并且实际选定方案呈现可感知的后方环境层次。轻量表面不要求呈现动态层次，但必须通过基础可用性和边缘稳定性检查。

## 七、术语

| 术语 | 定义 |
|---|---|
| 平台原生动态材质 | Windows 浮窗中可感知后方环境层次的半透明环境材质 |
| 轻量表面 | 动态材质不可用时仍保证可读、边缘完整和交互稳定的基础表面 |
| 单次运行 | 从应用启动到退出的一个连续使用周期 |
| 候选淘汰 | 某方案在本期实机验收中触发任一失败条件，不得作为生产方案 |
