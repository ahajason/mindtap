## 一、背景与目标

### 1.1 项目背景

ENFP 等创意人群每天在多任务间频繁切换,工作日 10:00 同时打开 IDE + 邮件 + 飞书,10:30 已忘记 IDE 里那个任务到底叫什么;下午复盘时回忆"这周做了什么"全凭主观感觉。

番茄钟类工具失败模式:主动启动 → 主动停止 → 主动分类,每一步都打断心流。

人进入 flow state 完全感知不到时间流逝,番茄钟 25min 振动是**已经晚了**的提醒。

### 1.2 项目目标

| 指标 | 目标 |
|---|---|
| 浮动窗触发到开始计时 | ≤ 3 秒 |
| 工作流被打断 | 0 次(永远不抢当前焦点) |
| 一周后能回忆每天做了什么 | ≥ 80% 任务 + 时长 |

### 1.3 核心用户

单人本地 Windows 11 用户,需要轻量记录"我在做什么 + 花了多久"。

## 三、功能详细设计

### 3.1 浮动窗折叠态

**功能描述**:浮窗默认态,单行显示当前任务 + 累计计时。

**用户场景**:
- Alice 在 IDE 写代码,瞥一眼右下角 → 看到"重构计时器 00:23:14" → 安心继续
- Bob 在浏览器查资料,瞥一眼 → 看到"查资料 00:05:30" → 记得自己在做什么

**交互流程**:
- 短按(无拖动):展开
- 拖动:移动浮窗位置
- 右键:弹退出菜单

**业务规则**:
- 浮窗物理尺寸 320×36(单行)
- 浮窗默认位置:主屏右下角,上移避开 Windows 11 任务栏(任务栏高 ~48px)
- 永远不抢当前焦点(用户切到任何 App,浮窗都不打断)
- 计时器每秒更新一次
- 任务名上限 50 字符(超出 UI 截断 + 提示)

**异常处理**:
- 数据存储失败:浮窗内显示错误 message
- 快捷键被其他程序占用:启动时检测并提示用户

### 3.2 浮动窗展开态

**功能描述**:输入新任务 + 开始计时(V0.2.0 只支持"新建",V0.2.1 才支持"选择已有")。

**用户场景**:
- Alice 早晨开工,浮窗是空的 → 单击展开 → 输入"写代码" → Enter → 折叠回 320×36,开始计时

**交互流程**:
- 单击折叠态 → 展开 360×280
- 输入任务名 → Enter / 点"开始" → 折叠 + 进入"进行中"
- Esc / 失焦 → 折叠(不创建)
- 任务名上限 50 字符(超出 UI 截断 + 提示)

**业务规则**:
- 浮窗物理尺寸 360×280
- 默认向上展开(避免覆盖任务栏)
- 全局同时只能有 1 个"进行中"任务

**异常处理**:
- 输入为空 / 全空格 → "开始"按钮 disabled
- 已经有"进行中"任务 → 提示"先完成当前任务"

### 3.3 任务状态机

**功能描述**:4 种动作:开始 / 暂停 / 恢复 / 完成。

**业务规则**:
- **开始**:创建新记录,初始状态=进行中,计时从 0 起算
- **暂停**:进行中 → 暂停,计时冻结
- **恢复**:暂停 → 进行中,计时从冻结值继续
- **完成**:进行中 / 暂停 → 已完成,记录完成时刻(此行不再变化)
- 全局同时只能有 1 个进行中(已有时不允许再开始新任务)
- 暂停时计时**冻结**(不增不减)
- 永久保留所有记录(不自动清理 / 不自动归档)

**异常处理**:
- 试图开始新任务但已有进行中:拒绝 + 提示用户
- 试图暂停已完成:拒绝 + 提示用户

### 3.4 持久化

**功能描述**:所有记录存本地数据库。

**业务规则**:
- 重启电脑后,进行中任务的计时从最后记录时刻继续累加(用户视角:跟离开时显示一致)
- 数据库文件只增不减

**异常处理**:
- 数据库文件损坏:启动时报错,提示用户
- 数据库写失败:浮窗内显示错误 message

### 3.5 窗口关系

**功能描述**:两个窗口如何协同。

**业务规则**:
- 关闭主窗窗口 → 主窗**隐藏**,浮窗继续计时,应用继续运行("后台驻留")
- 浮窗右键菜单 → 退出应用(本期唯一正退出入口)
- 主窗内容 = V0.1.6 Style Guide(本期不修改,沿用)

**异常处理**:
- (本期不涉及)

### 3.6 启动入口

**功能描述**:应用启动时哪些窗口出现。

**业务规则**:
- 启动时**主窗 + 浮窗都显示**

### 3.7 全局快捷键

**功能描述**:不打开主窗也能唤起/隐藏浮窗。

**业务规则**:
- Ctrl+Shift+Space:唤起 / 隐藏浮窗

**异常处理**:
- 快捷键被其他程序占用:启动时检测 + 提示用户

### 3.8 空状态

**功能描述**:首次启动 / 无进行中任务的浮窗样子。

**业务规则**:
- 显示空状态文案 + "新建"按钮
- 点击"新建"展开输入框

### 3.9 错误处理

**业务规则**:
- 错误流 = 用户可见的提示 message(具体形式:toast / 模态 / 浮窗内红字 → TBD,V0.2.0 spec UX grill 待补)
