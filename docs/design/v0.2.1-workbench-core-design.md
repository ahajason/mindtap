# V0.2.1 工作台账核心 — 设计 spec

> **定位**：浮窗「捕获 + 并行任务条」的视觉、交互、可访问性设计契约。玻璃参数只引用共享规范，不在此重复定义。
> **对应 Domain**：`docs/domain/v0.2.1-workbench-core-domain.md`
> **对应 Tech**：`docs/tech/v0.2.1-workbench-core-tech.md`

## 一、屏幕与状态

### 1.1 屏幕列表

| 屏幕 | 载体 | 触发 |
|---|---|---|
| **折叠条** | 浮窗 360×36 | 常驻 |
| **捕获面板（compose）** | 浮窗展开(输入专用) | 全局快捷键 / 折叠条点击 |
| **并行列表（list）** | 浮窗展开(卡片列表) | 浮窗内点开始/查看 |
| **失真确认气泡** | 独立小窗 280×80 | 失真检测触发 |

### 1.2 状态列表

| 状态 | 触发条件 | 视觉差异 |
|---|---|---|
| **折叠态·无活动** | 无进行中任务 | 状态点灰 + "未命名任务" + 00:00:00 |
| **折叠态·有活动** | 有进行中任务 | 状态点绿 + 任务名 + 累计计时 |
| **折叠态·待确认** | 有待确认失真窗口 | 折叠条上出现小圆点「待确认 N」(ADR-0012) |
| **捕获面板** | 快捷键/点击进入 | 单输入框 + 开始 + 取消 |
| **并行列表** | 点开始/查看 | 全部进行中卡 + 收件箱项(带最小开始按钮) |
| **失真气泡** | 冷却/跨天触发 | 独立小窗,「写代码 还在进行中,还要继续吗?」[继续] [暂停] |

## 二、组件契约

### 2.1 折叠条（复用既有 FoldedBar）

**职责**：单行展示当前状态 + 待确认标记。
**Props**（语义级）：
- 活跃任务数 / 收件箱未整理数 / 待确认数 / 是否展开
**视觉规范**：
- glass 等级：沿用既有折叠条（玻璃表面）
- 待确认小圆点：新控件，位置在右侧计时旁，用状态点同款样式但不同色（如琥珀色），不新增玻璃层
**交互状态**：
- 点击 → 进入捕获面板；已展开时点击 → 进入并行列表
**a11y**：
- role: status；aria-label 含活跃数 / 收件箱数 / 待确认数

### 2.2 捕获面板（compose，改造既有 ExpandedPanel）

**职责**：纯输入，无卡片列表。
**Props**（语义级）：
- 输入值 / 变更回调 / 提交 / 取消 / 上限 / 提交中
**视觉规范**：
- 输入框沿用既有（占位「当前在做什么」）
- 开始按钮在输入为空时禁用
**交互状态**：
- Enter → 保存进收件箱 + 折叠；Esc → 清输入 + 折叠；点面板外 → 只折叠保留输入
- 不显示任何卡片列表、历史下拉（历史复用已有存量，保留）
**a11y**：
- 输入框自动聚焦；aria-label 明确「捕获新任务」

### 2.3 任务卡（新 TaskCard）

**职责**：一张并行任务卡，四要素直接显示。
**Props**（语义级）：
- 内容 / 累计时长（实时滚动）/ 冷却深浅 / 进度备注 / 来源（manual）
- 收件箱项：额外「开始」按钮
- 进行中卡：点击「开始」= 切换到此卡（前一张自动退回待办）
**视觉规范**：
- glass 等级：卡片落非玻璃背景上（Liquid Glass 铁律——内容必须在非玻璃背景上）
- 冷却深浅：用透明度表达失真档位（活跃 100% / 冷却 65% / 晾着 40%），不新增控件
- 进度备注直接显示在卡上，不点开
**交互状态**：
- 卡片 hover → 略提亮；点击卡片区 = 切换到进行中；收件箱项有「开始」按钮
**a11y**：
- role: button（可点击开始）；每卡 aria-label 含内容 + 累计时长 + 冷却状态

### 2.4 失真确认气泡（新 Bubble）

**职责**：失真任务「还在进行中,还要继续吗?」主动询问。
**Props**（语义级）：
- 任务内容 / 待确认时长 / 确认回调（继续/暂停）
**视觉规范**：
- 独立小窗 280×80，玻璃拟态（透明 + 模糊 + 无装饰），延续 Liquid Glass
- 位置：屏幕右下角（避让右上角浮窗）
- 层级最高，不抢键盘焦点
**交互状态**：
- 5 秒无操作 → 自动暂停（只停不抹）；气泡转入「待确认」
- 用户回来 → 看到「刚才这 X 时间要计入吗?」[记入] [丢弃]
**a11y**：
- 气泡不抢焦点；两按钮可键盘操作；aria-live 提示

## 三、交互细节

### 3.1 全局快捷键捕获

**触发**：Ctrl+Shift+Space（沿用既有,仅改造行为）
**动效**：浮窗展开 + 输入框聚焦（不抢原窗口焦点,仅临时获得输入权）
**响应**：输入 → 回车 → 保存进收件箱 → 浮窗收起 → 焦点归还原窗口
**约束**：空内容不保存;Esc 取消;连续捕获 10 条不打断输入流

### 3.2 并行任务条（PRD 1.2）

**触发**：浮窗展开
**响应**：显示全部进行中卡 + 收件箱项;每卡四要素直接显示;点某卡「开始」→ 前一张自动退回待办（零成本切换,一个事务）
**约束**：超过 5 个进行中 → 浮窗轻提示「在推进的事有点多」(不阻止)

### 3.3 失真确认闭环（ADR-0012）

**触发**：冷却 2h 无更新 / 跨天
**响应**：独立气泡「写代码 还在进行中,还要继续吗?」[继续] [暂停] → 5 秒无操作自动暂停 → 气泡转入「待确认」 → 用户回来 [记入] [丢弃]
**动效**：气泡 200ms 淡入（不抢焦点）；超时暂停后气泡平稳过渡为「待确认」态
**约束**：计时只停不抹;失真窗口待确认;判定权在用户

### 3.4 重复捕获轻提示

**触发**：捕获时检测到同名已有卡
**响应**：浮窗内极轻视觉标识（如同名小圆点），不打断输入流
**约束**：不自动合并;判断交还用户
