# 0004 — V0.2 平台范围：锁 Windows，macOS 推迟到 V0.3

**Status**: accepted · 2026-07-11 · V0.2 立项
**引用警告**: 本 ADR 锁定 V0.2 平台决策；V0.3 macOS 接入方式待 V0.3 立项独立评估，**不**预设沿用 `.archive/` 实装

V0.2 仅交付 Windows 11/12。macOS 推迟到 V0.3（用户决策 Q4=A）。

## 候选方案

| 选项 | 工作量 | 风险 |
|---|---|---|
| **A** ✅ V0.2 锁 Windows | 1× 单平台 | Tauri WebView2 透明窗 + drag + global-shortcut 在 Windows 的差异**已实测**（2026-07-11 Windows build log，事实）|
| B V0.2 同步双端 | 2× 双平台 | macOS 平台差异的 dev 实测要做第 2 遍 |

## 后果（候选，待 V0.2 spec 确认）

- **+** V0.2 聚焦解决"Windows 上 WebView2 透明窗 + global shortcut"一套差异，验收范围收窄。
- **？** V0.3 接入 macOS 时是否复用 `.archive/` 实装代码—— **V0.3 立项时独立评估**，本 ADR 不预设（按 `archive-reference-only.mdc`，`.archive/` 任何内容都是非事实）。
- **+** dev 实测只盯 Windows 11 24H2 一台机器，符合 D43"跨环境开发不混用"原则。
- **−** V0.2.0 不能给 macOS 用户用——回归成本待 V0.3 立项评估。

## 平台能力登记 (通用技术事实, V0.3 立项时打开)

> ⚠️ 本节列举的是 **Apple / Windows 平台原生 API 能力**（通用技术事实），**不是 `.archive/` 内容**。`.archive/` 里的实装方案仅作历史参考，是否沿用待 V0.3 立项独立评估。

| 维度 | macOS 平台能力 | Windows 平台能力 |
|---|---|---|
| 透明窗口 + drag | NSWindow + `setMovableByWindowBackground`；Tauri 2 macOS 走 JS IPC 自动注入 drag.js | WebView2: `-webkit-app-region: drag` + capability `core:window:allow-start-dragging`（V0.1.6 retro 沉淀） |
| 全局快捷键 | `tauri-plugin-global-shortcut` | 同（需实测 Windows 注册是否被占用） |
| Liquid Glass | Apple NSVisualEffectView / SwiftUI 嵌入（Apple 官方 API）| CSS `backdrop-filter: blur(20px)` + `.glass-l1/l2/l3` token（项目自有 spec）|
| 不抢焦 | NSPanel `setFloatingPanel` + `becomeKeyOnly` (Apple 平台 API) | 待 V0.2 实测候选：`WS_EX_NOACTIVATE` 或 Tauri 2 `window.set_focus()` 抑制 |
