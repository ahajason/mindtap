## Why

阶段一(工作台账核心)已实机验证通过——「记得快、看得见」解决。但「台账可信」未闭环:最大漏记「干活了台账没记」只靠自觉;复盘只能手动看浮窗推断。阶段二(PRD 阶段二 S5/S6)要**系统主动发现漏记 + 2 分钟复盘**:

- 2.1 复盘视图:把「今天推进了什么、各投入多久、哪些晾着」一屏说清,未闭合任务逐条裁决;
- 2.2 活动信号:监听前台应用切换,10 分钟没计时 → 浮窗视觉强化 + 建议,把漏记递到眼前;
- 2.3 主窗管理:全列表(搜索/筛选/编辑)+ 删除 5 秒撤销,数据可控不怕输错。

**前置**:阶段一 1.4 的「系统通知 XX 已自动暂停」未真正生效(前端抢跑 + 权限未请求 + 无可关开关),并入 2.2 打扰级别配置一起补齐。
