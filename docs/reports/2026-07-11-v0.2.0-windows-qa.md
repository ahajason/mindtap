# 发现的问题(按 P0/P1/P2)

## P0 — 阻塞 V0.2.0 release

### P0-1: 版本号三处不一致
- `src-tauri/Cargo.toml:3` `version = "0.1.0"` ❌
- `package.json:3` `"version": "0.1.0"` ❌
- `src-tauri/tauri.conf.json:3` `"version": "0.2.0"` ✅

**后果**:NSIS 文件名是 `mindtap_0.2.0_x64-setup.exe`(从 tauri.conf.json 读),但 `mindtap.exe` 内部 Cargo product version 是 0.1.0 → Windows 资源管理器属性 → 详细信息 显示 0.1.0。

**根因**:WSL 端 `a90b045 chore(release): V0.2.0 — tauri.conf nsis + version 0.2.0` 只改了 tauri.conf.json,漏改 Cargo.toml + package.json。

**修复**:三处统一升到 `0.2.0`。

### P0-2: `dist/floating.html` 不存在(vite 多入口配置缺失)

**实测** `npm run build` 产出:
```
dist/index.html              0.48 kB
dist/assets/index-*.css     41.35 kB
dist/assets/index-*.js     442.57 kB
```
**没有 `dist/floating.html`**。

`vite.config.ts` build 块只有 minify/target/sourcemap,**没有 `rollupOptions.input`**。

**后果**:NSIS 安装后,`tauri.conf.json` `windows[1].url = "floating.html"` 加载 `frontendDist: "../dist/floating.html"` → 文件不存在 → 浮动窗运行时失败(404 / Tauri fallback 错误页 / 黑窗)。

**根因**:WSL 端 `ac0beca feat(floating): tauri.conf 加 floating window` commit message 写 "Vite 多入口: floating.html 平级于 index.html,Vite 6+ 自动发现多 HTML 入口,无需改 vite.config.ts" — **错的**。Vite 7 不会自动发现多 HTML,需要显式 `build.rollupOptions.input = { main: 'index.html', floating: 'floating.html' }`。

**修复**:
```ts
// vite.config.ts build.rollupOptions
input: {
  main: 'index.html',
  floating: 'floating.html',
}
```
**验收**:重跑 `npm run build` 必须产出 `dist/floating.html` + `dist/assets/floating-*.{css,js}`。

### P0-3: `floating.css` 没 `@import "tailwindcss"`,浮窗所有 Tailwind utility class 失效

`src/floating/styles/floating.css` 只定义原生 CSS(`.floating-root`, `.floating-root.folded`, `.floating-root.expanded`),**没有 `@import "tailwindcss";`**。

对比:`src/index.css` 顶部有 `@import "tailwindcss";` + `@theme { ... }`,main 入口 Tailwind 正常。

**实测**(chrome-devtools 加载 `http://localhost:1420/floating.html`):

| 维度 | main 入口 | floating 入口 |
|---|---|---|
| inline `<style>` 总长 | 67,051 B | **1,632 B** |

FoldedBar `className="glass-l2 flex cursor-pointer items-center justify-between rounded-full px-3 py-1 text-[12px]"` Computed:
- `display: block`(flex 不生效)
- `justify-content: normal`(justify-between 不生效)
- `border-radius: 0px`(rounded-full 不生效)
- `padding: 0px`(px-3 py-1 不生效)
- `background: rgba(0,0,0,0)` 透明(.glass-l2 在 floating.css 没定义)
- `cursor: auto`(cursor-pointer 不生效)

**后果**:浮窗折叠态根容器 OK(`.floating-root` 是原生 CSS 兜底),但**所有内部组件 (FoldedBar / StatusDot / InputBar / ControlRow / ContextMenu / ExpandedPanel) 视觉裸奔** — 文本堆叠无分隔、无圆角、无 padding。

**根因**:WSL 端 `5cf9c96 fix(floating): 补 .floating-root CSS 样式` 只补了根容器兜底,没补 floating.css 缺 Tailwind import。

**修复**:`src/floating/styles/floating.css` 顶部加 `@import "tailwindcss";` + 复用 `src/index.css` 的 `@theme { ... }` tokens(或新建 floating-local theme)。

### P0-4: ExpandedPanel 根 div 没挂 `.floating-root` 类

`src/floating/App.tsx:121-122`:
```tsx
return (
  <ExpandedPanel ... />
);
```
`src/floating/components/ExpandedPanel.tsx:82` 根 div:
```tsx
<div className="glass-l3 flex h-full flex-col gap-2 rounded-2xl p-3 text-[12px]">
```

CSS `src/floating/styles/floating.css:58` 已定义:
```css
.floating-root.expanded {
  width: 360px;
  height: 280px;
  min-width: 360px;
  min-height: 280px;
  border-radius: 18px;
  user-select: none;
}
```

**后果**:展开态不应用 `.floating-root.expanded` 兜底(360x280, radius 18px)。展开态实际尺寸依赖 webview resize + 仅靠 ExpandedPanel 内部 Tailwind class(且 Tailwind 全失效,见 P0-3)。

**修复**:`ExpandedPanel.tsx` 最外层 div 改:
```tsx
className="floating-root expanded glass-l3 flex h-full flex-col gap-2 rounded-2xl p-3 text-[12px]"
```

- V0.2 仅 Windows 不阻塞,V0.3+ 适配 macOS 时必须改

**修复**:改为 `com.mindtap.desktop` 或 `io.ahajason.mindtap`。

### P1-3: esbuild CSS calc warning
```
[esbuild css minify] WARNING: The "-" operator only works if there is whitespace on both sides
calc(0-9 * var(--tw-space-y-reverse))
```
不影响产物,但污染构建日志。Tailwind v4 生成 `calc(0-9 * ...)`,esbuild 严格校验失败(警告不阻断)。等 Tailwind 升级修复或抑制。
