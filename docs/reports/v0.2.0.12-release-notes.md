## 用户视角摘要(5 行)

1. **右键浮窗弹操作系统原生菜单**(显示主窗 / 退出 / 自动启动 / 取消;菜单弹在浮窗外,不裁剪,4 项全可见);之前 HTML React 菜单被浮窗 viewport 裁剪/跑到屏幕边缘看不见
2. **折叠态状态指示(StatusDot)在浮窗最左**(标题前面 8×8 小圆点,active 绿色呼吸 / paused 橙色常亮 / completed 灰色);之前"V0.2.x 右上角 absolute"是 V1.0 archive 不存在的前提  <!-- [V0.2.0 误导] -->
3. **浮窗无 1px 黑边**(无论 TS 内容是否清空,focus / unfocus 视觉完全一致);之前 WebView2 transparent + DWM aura shadow 产生 1px 黑边,focus 后更明显
4. **展开态内点 Start 能开启 Active 任务**(展开态内点击不再被 input blur 吞掉);之前 input blur 同步触发 onCancel,Start 按钮 click 失效
5. **D:\ 端需 Ctrl+C 重启 `scripts\dev.bat`**(tauri.conf.json 改 `shadow: false` 需重启 WebView2)

## 技术摘要(开发者)

### A — ContextMenu = Rust 原生 Menu(`window.popup_menu`)

**真相来源**: V1.0 archive `.archive/src-tauri/src/tray/menu.rs` + `.archive/src-tauri/src/commands/floating_cmd.rs:78-94`

- **删**: `src/floating/components/ContextMenu.tsx`(HTML React, V0.2.6 误改产物)+ 对应 test
- **新建**: `src-tauri/src/tray/{mod.rs, menu.rs, confirm.rs}`(沿用 V1.0 archive 目录结构)
- **新建**: `src-tauri/src/commands/floating_cmd.rs`(`show_floating_context_menu` command)
- **改**: `src-tauri/src/lib.rs` — `.plugin(tauri_plugin_autostart::init(...))` + `.on_menu_event(...)` 绑定 + `invoke_handler!` 加新 command
- **改**: `src-tauri/Cargo.toml` — 加 `tauri-plugin-autostart = "2"`
- **改**: `src/lib/tauri-bridge.ts` — `app.showFloatingContextMenu` wrapper
- **改**: `src/floating/App.tsx` — `onContextMenuCapture` 内 `await api.app.showFloatingContextMenu()`(替代 `setContextMenu`)

### B — StatusDot = inline-block flex 第 1 child(最左)

**真相来源**: V1.0 archive `.archive/src/floating/StatusDot.tsx` + `FoldedBar.tsx` + `styles/focus-block.css:71-88 + 163-171`

- **改**: `src/floating/components/StatusDot.tsx` — 删 `POSITION_CLASS` map(`absolute top-1 right-1`),恢复 V1.0 archive inline-block 8×8 span
- **改**: `src/floating/components/FoldedBar.tsx` — `<StatusDot status={status} />` 不传 `position` prop(FoldedBar flex container 第 1 child)
- **改**: `src/floating/App.tsx` — 折叠态 JSX `<StatusDot status={...} />` 不带 `position="absolute"`
- **改**: `src/floating/styles/floating.css` — 删 `.floating-root { position: relative }`(V0.2.0.11 B fix 加的,误导),恢复 V1.0 archive `.dot` flex item 样式 + `@keyframes pulse 1.6s`

### C — Rust 黑边 = `shadow: false` 单字段 fix

**真相来源**: Tauri 2 官方文档 + issue #9287 + #13176 直接命中

- **改**: `src-tauri/tauri.conf.json` floating 段:
  - 加 `"shadow": false`(Tauri 2.11.3 `WindowConfig` 默认 `shadow: true`,在 `decorations: false` 下产生 1px border / Win11 aura shadow / focus 后加重)
  - `"resizable": true` → `false`(浮窗固定 320×36 不需要 resize,避免 non-client edge / resize grip 残留)
  - 保留 V0.2.0.11 已加的 `transparent: true` + `backgroundColor: "#00000000"`
- **不改**: main 窗口配置(main 走另一条 DWM 路径,无依据不盲改)

### D — Active 开启路径 = Radix pointerdown capture

**真相来源**: Radix UI `dismissable-layer.tsx` 用 `onPointerDownCapture` 在 panel 根 div 设 `isPointerInsideReactTreeRef`,比 `blur` 早一拍

- **改**: `src/floating/components/ExpandedPanel.tsx`:
  - 加 `panelRef = useRef<HTMLDivElement|null>(null)` + `dismissingRef = useRef(true)`(默认 panel 外才 cancel)
  - panel 根 div 加 `ref={panelRef}` + `onPointerDownCapture={(e) => { dismissingRef.current = !panelRef.current?.contains(e.target as Node); }}`
  - `handleBlur` 改为 `if (submittingRef.current) return; if (dismissingRef.current) onCancel();`
  - **blur listener 不删,只改逻辑**
- **不改**: `src/floating/App.tsx` — 所有 `data-no-expand` / `e.button !== 0` / `onContextMenuCapture` 守卫保留原状(V0.2.0.11 layer 守卫保留,V0.2.0.12 在 ExpandedPanel 内新增 layer)
