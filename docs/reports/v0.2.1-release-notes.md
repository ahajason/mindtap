## TL;DR

V0.2.1 = 在 V0.2.0 浮窗展开态**叠加** SwitchDropdown — 让用户从最近 5 个不同 `task_title` 中挑一条复用 → 创建新 `timer_session` 后立即 active。V0.2.0 折叠态 + 手动输流程**不变**;V0.2.1 是叠加,不改 3 态状态机、不改折叠态、不改 db schema。

## 包含 (V0.2.1 范围内)

- ✅ **SwitchDropdownSection** (展开态 popover overlay): ARIA listbox, 最近 5 个不同 `task_title`, 末次使用倒序
- ✅ **EmptyHistoryHint** (9.6-C): 0 条 completed session 时显示引导气泡 `👋 还没有历史任务,先新建一个试试?`, 点击 → 焦点跳到 InputBar
- ✅ **useRecentTaskTitles** hook: 30s 内存缓存, IPC 失败时返回 `[]`
- ✅ **db::timer_session.list_recent_task_titles**: SQL `GROUP BY task_title ORDER BY MAX(completed_at) DESC LIMIT 5`
- ✅ **IPC 命令**: `timer_session_list_recent_task_titles_cmd(limit: Option<i64>)`, 前端默认 limit=5
- ✅ **bridge wrapper**: `tauri-bridge.listRecentTaskTitles()`, `TaskTitleRec` TS 类型
- ✅ **NSIS bundle** 持续启用: `bundle.targets = ["nsis"]` (V0.2.0 release `a90b045` 已启用, V0.2.1 patch `ad1e14b` 保持)
- ✅ **9 项 spec v1.1 grill 全部锁定** (spec §九)

- [ ] **S12 无历史记录的 SwitchDropdown**: 首次启动时展开 (db 无 completed session) → SwitchDropdown 区段**隐藏**, **仅显示 EmptyHistoryHint 引导气泡** → 点击引导气泡 → 焦点跳到 InputBar
- [ ] **S13 取消选择**: SwitchDropdown 弹出 → 关闭 → 回到 InputBar (无新 session, db 无半提交行)

- [ ] 折叠态位置持久化 (主屏右下角 -100px, localStorage 存)
