色彩与光线

更新于 17:42 · 248 字 · #颜色 #光 #碎片

今天路过便利店，玻璃门打开的那一瞬间，冷气与暖色灯光同时扑到脸上。我站在那里多看了几秒——这就是我要写的东西：边界处的颜色。

四种看见

雨后路面是深灰偏紫，地铁反光是冷青里带一点钴蓝，咖啡杯边是奶油色被蒸汽打断，便利店冷光是带荧光的惨白。它们之间没有过渡，只有切换。

颜色其实是边界。两种光相遇的地方，颜色才真正存在。
本周颜色切片
  • 周一 · 地铁口 · 钴蓝 + 暖白
  • 周二 · 早餐摊 · 鸡蛋黄 + 不锈钢
  • 周三 · 雨后 · 深灰偏紫
  • 周四 · 便利店 · 荧光惨白
  • 周五 · 回家路上 · 路灯暖橙

下一步

把它们做成小色卡，每张只有一种颜色 + 一句话描述。再看看一周下来，能不能拼出我自己的一天。
