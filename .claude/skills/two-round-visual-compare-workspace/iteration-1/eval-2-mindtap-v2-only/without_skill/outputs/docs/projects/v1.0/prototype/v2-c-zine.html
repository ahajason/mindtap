我的一周，被颜色串起来

雨后路面 🟣

周一下了 20 分钟的雨。雨停之后，路面反射着天空的紫灰。我特意绕了远路。这种颜色没有名字——它不是紫，也不是灰，更像一种"刚刚下过"的氛围。

↳ 19:42 · 国贸桥下

地铁反光 🔵

周二早高峰，车厢连接处的金属条反着站台灯光。冷青、钴蓝、暖白挤在一条 8cm 宽的金属条上。我盯着它看了三站。

  • 冷青色打底
  • 钴蓝压在上层
  • 暖白来自对面

咖啡杯边 ☕

奶油色的咖啡被蒸汽打断，杯沿出现一圈极淡的橙。这圈橙不是来自咖啡，而是来自对面暖光灯的反射。照片里没有那种"被打断"的感觉。
