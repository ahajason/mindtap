Component: <PipelineTable/>

The component used in the dashboard. Props match the JSON:API schema 1:1 — no surprise renames.

deals*
Array of deal resources. See GET /v1/deals for the canonical shape.
Deal[]
density
Visual row height. "compact" removes cell padding; "regular" is the default.
"compact"|"regular"
onStageChange
Called with (dealId, fromStage, toStage) after a successful drag. The component is fully controlled — it does not mutate the deal directly.
(id, s, s) => void
filter
Optional client-side filter expression. Server-side filtering should use the ?filter= query param on the list endpoint instead.
FilterExpr?
emptyState
Slot for the empty list. Defaults to "No deals match the current filter."
ReactNode

Example

import { PipelineTable } from "@stackdesk/ui";

export default function function Page() {
  const { deals, moveDeal } = useDeals();

  return (
    <PipelineTable
      deals={deals}
      density="compact"
      onStageChange={(id, from, to) => moveDeal(id, to)}
    />
  );
}

Resource tree

All reads use the path prefix /v1/<resource>. Mutations require a Idempotency-Key header on POST/PATCH.

/v1
├── /workspace/{id}
│   ├── GET    — workspace + summary
│   └── /members
├── /deals
│   ├── GET    ?filter=stage:commit&sort=close_date
│   ├── POST   — create (Idempotency-Key required)
│   └── /{id}
│       ├── GET
│       ├── PATCH
│       └── /stage
│           └── POST — { to: "commit" } (audit-logged)
├── /accounts
│   ├── GET
│   └── /{id}
└── /webhooks
    ├── POST   — subscribe
    └── /{id}  — rotate secret
