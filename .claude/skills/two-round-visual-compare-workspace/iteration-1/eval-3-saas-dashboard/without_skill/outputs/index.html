SaaS dashboard redesign

From purple-pink glass template to four real directions

The previous design was 28px headlines, a centered frosted card, and a purple-to-pink gradient — the AI-slop default. This folder contains two rounds of comparison built to actually decide, not to perform design: first, how much glass (4 density variants of the same dashboard over the same warm background); then, four context directions (macOS 26, Linear-style dark, editorial magazine, engineering doc) using the same real pipeline data.

Round 1

Glass density

Four variants of the same dashboard over the same warm sunset background. The comparison axis is how much glass — not what kind. Pick the level that lets the chrome float without sacrificing legibility.

Round 2

Context directions

Four full 1280×800+ pages, each in its own tab, with the same KPI / pipeline / activity data underneath. Glass only on controls, never on content. Distinct fonts per direction. Open all four side-by-side to feel the difference.
