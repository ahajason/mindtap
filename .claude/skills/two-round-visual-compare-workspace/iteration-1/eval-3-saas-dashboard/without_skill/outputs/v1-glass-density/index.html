Glass density, 4 levels

Same SaaS dashboard, same warm-sunset background, same KPI / pipeline / activity content. The only thing that changes is how much glass the chrome uses. Open compare.html for the full side-by-side, or click a variant to look at it in isolation.

A · Ultra-thin

10% white tint · 6px blur · saturate 110%
Open ↗
Almost no glass — the gradient bleeds through everything. Sidebar text fights the background, KPI numbers get halo'd by warm orange. Pure aesthetic statement, not a usable product. Use only on hero / marketing.
where: hero / marketing trade: illegible

B · Regular

55% white tint · 20px blur · saturate 140%
Open ↗
The standard "macOS frosted" recipe. Cards float, type stays legible, the warm gradient still shows through the sidebar. Reads as a real Apple-style app, not a template. The default for product UI.
where: primary product UI trade: balanced

C · Thick

92% cream tint · 40px blur · saturate 160%
Open ↗
Glass that's so dense it's basically opaque cream paper. Loses the "glass" character but wins on accessibility and dense data. Reads more like a printed page on a poster than a translucent app.
where: dense data, a11y trade: not glass anymore

D · Hybrid (HIG pattern)

Chrome = 30% / 10px · Content = solid
Open ↗
The Apple HIG way: glass is for controls (sidebar, topbar, search) only; content cards stay solid. The gradient still shows in the chrome, the content stays perfectly readable. Best of both. The production answer.
where: production trade: none
