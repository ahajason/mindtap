How to read the matrix

  • Light vs Heavy — the glass itself: thin regular vs thick saturate + dim. Density of the control layer.
  • Creative vs Strict — the shape language: warm radius / color / serif vs neutral radius / sans / mono.
  • Real content sits behind the glass (KPI rows, invoice tables, chart, command palette). Glass is only on top bar, side bar, toolbar, FAB — never on content cards.
  • Pick a quadrant (Q1–Q4) and optionally one D-variant. That answer becomes the density of the V2 page.
