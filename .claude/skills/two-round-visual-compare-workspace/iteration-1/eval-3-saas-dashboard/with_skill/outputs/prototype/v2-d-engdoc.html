POST /v1/invoices

Status: Stable Since: 2024-08-12 Idempotency: required Latency p95: 142ms

Creates a draft invoice for a customer. The invoice is not finalized until POST /v1/invoices/{id}/finalize is called, at which point a invoice.created event is emitted. Use the dashboard component <InvoiceTable /> to render the resulting list — it accepts the same filter and sort parameters as the list endpoint.

Request body

FieldTypeDescription
customerstring <ulid> *ID of the customer. Must exist in /v1/customers.
currencyenum <iso-4217>Three-letter ISO currency code. Defaults to USD.
line_itemsarray<LineItem> *Minimum 1 item. See schema below.
collection_methodenumcharge_automatically | send_invoice. Default: charge_automatically.
days_until_dueintegerFor send_invoice only. 1–90. Default: 30.
metadataobject<string,string>Up to 50 keys, 40 chars each. Returned verbatim.

Example

// Create an invoice for Northwind Labs (12 Pro seats, prorated mid-cycle)
const invoice = await northwind.invoices.create({
  customer: "01HX9...",
  currency: "USD",
  line_items: [
    { plan: "pro", quantity: 12, period: { start: "2026-06-01", end: "2026-06-30" } }
  ],
  collection_method: "charge_automatically",
  metadata: { source: "dashboard.upgrade.modal" }
}, { idempotencyKey: "upgrade-41b3e0" });

Component <InvoiceTable />

Used on the Overview and Billing pages. Renders a sortable, filterable table backed by GET /v1/invoices. The component also exposes a filter prop that maps directly to the query string:

PropTypeDescription
filter.status"active" | "past_due" | "trial" | "all"Defaults to active.
filter.plan"starter" | "team" | "pro"Single plan only.
sort"mrr" | "renewal" | "created"Defaults to mrr. Always desc.
pageSizeinteger10, 25, 50. Default 25.
onRefund(id: string) => voidCallback fired when the row's refund action is triggered.
