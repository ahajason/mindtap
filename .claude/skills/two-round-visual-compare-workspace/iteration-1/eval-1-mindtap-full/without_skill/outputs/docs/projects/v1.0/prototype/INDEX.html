方法

对比方法

两轮的意义

  • Round 1（4 象限）：从「密度」与「编辑性」两轴出发，用最少的视觉成本定位整体感觉。不展示完整页面，只展示风格签名。
  • Round 2（4 落地）：把选定的方向做成完整的 1440×900 页面，使用真实的内容（同一组笔记样本）来对比，避免风格只是审美而不可用。

约束

  • Liquid Glass 只在控件层和导航层使用（侧栏 / 工具栏 / 浮动按钮 / 搜索框）。内容层（笔记卡、表格行、编辑画布）不施加玻璃，以保可读性。
  • 不使用紫色渐变 / 不使用过度发光的「AI 套路」配色。每个方向有自己的色彩个性（暖 / 中 / 深）。
  • 同一组数据：4 条笔记样本（灵感 / 打卡 / 待办 / 阅读），4 个方向共用，便于比较。
  • 视口统一 1440×900；macOS 窗口装饰统一，避免窗口本身干扰判断。

判据

  1. Glass for controls, not for content — 内容是否呼吸得开？
  2. 真实 5 秒 — 想象打开后 5 秒，看到的第一信息是什么？是否符合「极简记录」？
  3. 跨平台一致性 — 同一页能否平移到 iPad / iPhone？
  4. 本地存储的体感 — 数据感是否「在你的机器上」，而不是「在云端」？

详细方法见 docs/projects/v1.0/compare-method.md。
