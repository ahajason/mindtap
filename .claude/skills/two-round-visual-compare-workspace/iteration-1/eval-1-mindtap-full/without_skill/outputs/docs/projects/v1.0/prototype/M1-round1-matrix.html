X 轴：Creative vs Strict

Creative 倾向媒体优先（大图、卡片、叙事）、编辑性、节奏慢。Strict 倾向表单优先（表格、过滤器、批量操作）、数据、效率高。这决定 mindtap 是「日记本」还是「工作台」。

Y 轴：Light vs Heavy

Light = 浅色主调、玻璃薄、留白多。Heavy = 深色主调、玻璃厚、信息密度大、强调层次。这决定一天里打开的「视觉负担」——晨间偏好 Light，深夜偏好 Heavy。
