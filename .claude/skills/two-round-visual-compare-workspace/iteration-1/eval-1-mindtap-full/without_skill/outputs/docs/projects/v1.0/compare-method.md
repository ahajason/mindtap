# mindtap V1.0 · 视觉方向对比方法

> 用两轮 HTML 决策「极简记录 app」的视觉方向。Liquid Glass 是既定设计语言，本方法不重新发明它，只回答「具体落在哪个象限、用什么节奏呈现」。

## 为什么是两轮，而不是直接 4 个候选

直接抛 4 个完整页面做对比，决策负担太重——审美被细节（按钮位置、字号、行距）劫持，看不清整体方向。两轮的目的：

| 轮次 | 任务 | 粒度 | 输出 |
|---|---|---|---|
| **Round 1** | 定位整体方向 | 「这是什么感觉」 | 1 个 4×4 矩阵 + 4 个 1440×900 风格签名页 |
| **Round 2** | 落地为真实界面 | 「日常打开它长什么样」 | 4 个完整页面，使用同一组真实笔记样本 |

Round 1 只回答 2 个问题：**重还是轻？**、**编辑性还是表单？**。一旦这两轴选定了，Round 2 才在该方向上做完整页面。

## 两轴

```
                编辑性 · 媒体化（Creative）        表单 · 数据（Strict）
            ┌─────────────────────────────┬─────────────────────────────┐
   轻 (L)  │  Q1 暖色 + clear 玻璃 + 卡片  │  Q2 中性灰 + 轻玻璃 + 表格    │
            ├─────────────────────────────┼─────────────────────────────┤
   重 (H)  │  Q3 深色 + aurora + 大玻璃    │  Q4 深色 + 高密度表格         │
            └─────────────────────────────┴─────────────────────────────┘
```

- **轻 (Light)**: 浅色主调，玻璃薄，留白多。一打开「感觉轻」。
- **重 (Heavy)**: 深色主调，玻璃厚，信息密度大。一打开「感觉沉」。
- **Creative**: 媒体优先——大图、卡片、慢节奏叙事，像翻日记本。
- **Strict**: 表单优先——表格、过滤器、批量操作，像写工作日志。

## 与 Liquid Glass 的关系

Apple 的 HIG Materials 规定 Liquid Glass 用于**控件与导航**（tab bar、sidebar、toolbar、floating button、search field），**不用于内容层**。本方法严格遵守这条边界：

| 层 | Liquid Glass? | 例子 |
|---|---|---|
| 窗口装饰（titlebar） | ✅ 是 | traffic lights + toolbar group |
| Sidebar / Inspector | ✅ 是 | background extension effect |
| Toolbar / Filter bar | ✅ 是 | 多个 glass 按钮 → GlassEffectContainer |
| Floating [+] 按钮 | ✅ 是 | prominent 玻璃变体 |
| 笔记卡 / 表格行 | ❌ 否 | 浅色描边 + 微阴影 + 透明白 |
| 编辑画布 | ❌ 否 | 纯白背景，无任何玻璃 |

变体选择规则：

- 背景**视觉丰富**（aurora / 暖色 blob）→ `.clear` 变体
- 背景**中性**（纯灰 / 深色无装饰）→ `.regular` 变体
- 弹窗 / alert / 含大量文字 → `.regular`

## 真实样本一致性

所有 4 个方向共用同一组内容（避免「审美好看但不可用」）：

| 数据 | 值 |
|---|---|
| 笔记样本 | 4 条：灵感 / 打卡 / 待办 / 阅读 |
| 笔记字数 | 真实日记长度（60-120 字），不缩短到 1 行 |
| 标签 | #灵感 #随笔 #阅读 #打卡 #运动 |
| 时间 | 06-08 ~ 06-14（包含跨日） |
| 数量 | 142 条全部 / 本周 6 条 |
| 应用名 | mindtap（已确定） |

只有内容**用真的**，方向对比才有意义。

## 约束

1. **不写紫色渐变**。每个方向有自己的色彩个性。
2. **不写发光的玻璃 blob**（AI 套路）。玻璃用真实的 blur(40-60px) saturate(160-200%) 实现。
3. **不写 emoji 当 UI 元素**（仅作为视觉点缀）。
4. **视口统一 1440×900**。macOS 窗口装饰统一。
5. **CSS only**——无 JS、无图片、无外部依赖。可双击在浏览器打开。

## 判据（怎么挑）

按以下 4 条打分（每条 0-2）：

1. **Glass for controls, not for content** — 玻璃有没有克制？
2. **真实 5 秒** — 打开后 5 秒看到的第一信息是否符合「极简记录」？
3. **跨平台一致性** — 同一页能否平移到 iPad / iPhone（保留信息架构）？
4. **本地存储的体感** — 数据感是否「在你的机器上」，而不是「在云端」？

总分 8，>= 6 的方向进入 Round 3 决策。

## Round 1 → Round 2 映射

| Round 1 象限 | Round 2 完整页 | 命名 |
|---|---|---|
| Q1 Light+Creative | D7 自适应 | 暖色 + clear 玻璃 + dock + 浮动按钮 |
| Q2 Light+Strict | D8 表达式 | 中性灰 + 编辑器居中 + 格式化玻璃栏 |
| Q3 Heavy+Creative | D5 沉浸式 | 深色 + aurora + 单篇叙事 + 大玻璃 |
| Q4 Heavy+Strict | D6 工作台 | 深色 + 表格 + 状态列 + KPI |
