Liquid Glass — Design Language

The official design language for mindtap v1.0. Based on Apple HIG · Materials. Glass is reserved for controls and navigation surfaces; content lives behind glass in a separate surface layer.

§ 1 — Definition

glass is a translucent surface material applied to controls and navigation elements. It floats above the content layer, establishing visual hierarchy between functional elements (topbar, sidebar, FAB) and content elements (cards, lists, text blocks).

Rule. Never apply glass to a content card. Content lives in surface tokens, not glass.

§ 2 — Token tree

// styles/glass.css
--surface
  ├── --surface-canvas        /* page bg */
  ├── --surface-raised        /* content card */
  └── --surface-sunken        /* wells, code */

--glass
  ├── --glass-topbar          /* top controls */
  ├── --glass-sidebar         /* side nav */
  ├── --glass-fab             /* floating action */
  ├── --glass-menu            /* popovers */
  └── --glass-tooltip

--tint
  ├── --tint-default          /* monochromatic */
  └── --tint-amber            /* primary action */

§ 3 — Variants

Two variants are exposed. Choose by use case, not by visual appearance.

VariantBlurOpacityUse case
regular 20px 55–70% Default. Topbar, sidebar, FAB, menu.
clear 14px 18–28% Over visually rich content. Hero media.

§ 4 — Properties

The glass surface must include a 1px mirror highlight.

PropTypeDefaultDescription
blur px 20 backdrop-filter blur radius
saturation % 180 saturate() multiplier for content behind glass
tint color none Apply sparingly; primary actions only.
radius px 12 Concentric with container corner.
mirror bool true 1px inset top highlight + bottom shadow.

§ 5 — Implementation

// src/styles/glass.css
.glass-topbar {
  background: rgba(245, 245, 247, 0.65);
  backdrop-filter: saturate(180%) blur(28px);
  border-bottom: 1px solid rgba(0,0,0,.08);
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.6),  /* mirror */
    inset 0 -1px 0 rgba(0,0,0,.04);
}
Gotcha. Do not stack glass on glass. Use GlassEffectContainer (or its CSS equivalent) when multiple glass elements appear together.

§ 6 — Do not

linear-gradient(135deg, #667eea, #764ba2) on a centered max-width: 480px card with font-size: 28px headline. That is what every AI slop page looks like. Do not build that.
